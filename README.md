# termcn

Terminal-inspired components built on shadcn/ui. Catppuccin Mocha, JetBrains Mono, sharp edges.

## Documentation

Visit https://termcn.com/docs to view the documentation.

## Installation

```bash
npx shadcn@latest add https://termcn.com/r/styles/termcn/button.json
```
