# Button

Terminal-style outlined button with bracket convention, focus state inversion, and no hover/radius/shadow.

Follows TUI aesthetic: interaction via focus only, monospace typography, sharp edges, depth via background levels.

## Installation

<InstallTabs pkg="@termcn/button" />

## Usage

```tsx
import { Button } from "@/components/ui/button"

export default function ButtonDemo() {
  return <Button>Click me</Button>
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `default` \| `primary` \| `destructive` \| `ghost` | `default` | Button color scheme |
| `size` | `default` \| `sm` \| `icon` | `default` | Button size |
| `bracket` | `boolean` | `true` | Render `[label]` style brackets |
| `asChild` | `boolean` | `false` | Render as child element (Radix Slot) |
| `disabled` | `boolean` | `false` | Disable button |
| `className` | `string` | — | Additional Tailwind classes |
| ...rest | `ComponentProps<"button">` | — | All standard `<button>` props |
