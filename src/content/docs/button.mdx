# Button

Terminal-style button — filled by default, with an `outline` variant for borders — that lightens while pressed, with no hover/radius/shadow.

Follows TUI aesthetic: interaction via active (pressed) lightening and a focus ring — no hover — monospace typography, sharp edges, depth via background levels.

## Installation

<InstallTabs pkg="@termcn/button" />

## Usage

```tsx
import { Button } from "@/components/ui/button"

export default function ButtonDemo() {
  return <Button>Click me</Button>
}
```


Buttons are filled by default — `default` uses a muted surface, `primary` and `destructive` use their semantic color. Use `outline` for a bordered, transparent button and `ghost` for no chrome at all. While pressed (`:active`) a filled button lightens and a transparent one fills in — the feedback a TUI gives when you select a control. Keyboard focus shows a ring (`:focus-visible`). There is no hover state.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `default` \| `primary` \| `destructive` \| `outline` \| `ghost` | `default` | Button color scheme |
| `size` | `default` \| `sm` \| `icon` | `default` | Button size |
| `bracket` | `boolean` | `false` | Render `[label]` style brackets |
| `asChild` | `boolean` | `false` | Render as child element (Radix Slot) |
| `disabled` | `boolean` | `false` | Disable button |
| `className` | `string` | — | Additional Tailwind classes |
| ...rest | `ComponentProps<"button">` | — | All standard `<button>` props |
