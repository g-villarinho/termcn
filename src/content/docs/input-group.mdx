# Input Group

Composable input group with addons, embedded buttons, and text labels. Supports inline and block addon placement.

Follows TUI aesthetic: focus ring propagates from the group container, clicking any addon focuses the control, no hover states.

## Installation

<InstallTabs pkg="@termcn/input-group" />

## Usage

```tsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupText,
  InputGroupInput,
  InputGroupTextarea,
} from "@/components/ui/input-group"

export default function InputGroupDemo() {
  return (
    <InputGroup>
      <InputGroupAddon>$</InputGroupAddon>
      <InputGroupInput placeholder="0.00" />
    </InputGroup>
  )
}
```

## Notes

- Clicking any `InputGroupAddon` focuses the nearest `[data-slot=input-group-control]` within the group.
- The `data-slot="input-group-control"` attribute marks the focusable element — both `InputGroupInput` and `InputGroupTextarea` carry it.
- For `block-start` / `block-end` addons, add `flex-col items-stretch` to the `InputGroup` to switch layout direction.
- The focus ring (`focus-within:ring-1`) is applied at the `InputGroup` level, not per child.
