# Dropdown Menu

Terminal-style dropdown menu. Content appears below the trigger with a 150ms fade animation. Items highlight via foreground inversion (`bg-foreground text-background`) — no hover, keyboard navigation only via Radix.

Supports checkbox items (`✓` indicator), radio groups (`●` indicator), sub-menus, keyboard shortcuts, labels, separators, and inset items.

## Installation

<InstallTabs pkg="@termcn/dropdown-menu" />

## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuTrigger,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuSeparator,
} from "@/components/ui/dropdown-menu"

export default function Demo() {
  return (
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <Button>Open</Button>
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        <DropdownMenuItem>Item</DropdownMenuItem>
        <DropdownMenuSeparator />
        <DropdownMenuItem>Another item</DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  )
}
```

## Props

| Sub-component | Purpose | Key props |
|---|---|---|
| `DropdownMenu` | Root state provider | `open`, `onOpenChange`, `defaultOpen`, `modal` |
| `DropdownMenuTrigger` | Button that opens the menu | `asChild` |
| `DropdownMenuPortal` | Renders content in a portal | `container` |
| `DropdownMenuContent` | Floating menu panel | `sideOffset` (default: `4`), `side`, `align`, `className` |
| `DropdownMenuItem` | Clickable menu item | `inset`, `disabled`, `onSelect`, `className` |
| `DropdownMenuCheckboxItem` | Item with `✓` indicator | `checked`, `onCheckedChange`, `disabled`, `className` |
| `DropdownMenuRadioGroup` | Radio group container | `value`, `onValueChange` |
| `DropdownMenuRadioItem` | Item with `●` indicator | `value`, `disabled`, `className` |
| `DropdownMenuLabel` | Non-interactive section label | `inset`, `className` |
| `DropdownMenuSeparator` | Horizontal rule between sections | `className` |
| `DropdownMenuShortcut` | Right-aligned shortcut hint | `className` |
| `DropdownMenuGroup` | Groups items for accessibility | — |
| `DropdownMenuSub` | Sub-menu root | `open`, `onOpenChange`, `defaultOpen` |
| `DropdownMenuSubTrigger` | Item that opens a sub-menu | `inset`, `className` |
| `DropdownMenuSubContent` | Sub-menu floating panel | `className` |

## Notes

Built on [Radix UI Dropdown Menu](https://www.radix-ui.com/primitives/docs/components/dropdown-menu). All keyboard navigation (arrow keys, Enter, Escape, Tab) is handled by Radix — no custom event handlers needed.

Items highlight via `data-[highlighted]:bg-foreground data-[highlighted]:text-background` (foreground inversion), matching Vim's visual mode selection. No `hover:` variants are used.

Content and sub-content fade in/out via `termcn-fade` / `termcn-fade-out` keyframes (≤150ms). No scale or slide animations.
