# Menubar

Terminal-style desktop menubar — a horizontal bar with dropdown menus, styled with a bottom border. `Menubar` is the bar container, `MenubarMenu` wraps each dropdown, `MenubarTrigger` is the clickable bar item.

Triggers highlight via foreground inversion when open (`data-[state=open]`) or focused (`focus-visible:`). Dropdown items follow the same pattern as Dropdown Menu — keyboard navigation only, no hover.

## Installation

<InstallTabs pkg="@termcn/menubar" />

## Usage

```tsx
import {
  Menubar,
  MenubarMenu,
  MenubarTrigger,
  MenubarContent,
  MenubarItem,
  MenubarSeparator,
  MenubarShortcut,
} from "@/components/ui/menubar"

export default function Demo() {
  return (
    <Menubar>
      <MenubarMenu>
        <MenubarTrigger>File</MenubarTrigger>
        <MenubarContent>
          <MenubarItem>
            New file
            <MenubarShortcut>⌘N</MenubarShortcut>
          </MenubarItem>
          <MenubarSeparator />
          <MenubarItem>Quit</MenubarItem>
        </MenubarContent>
      </MenubarMenu>
    </Menubar>
  )
}
```

## Props

| Sub-component | Purpose | Key props |
|---|---|---|
| `Menubar` | Horizontal bar container | `className` |
| `MenubarMenu` | Wraps each trigger+content pair | — |
| `MenubarTrigger` | Clickable bar item | `className` |
| `MenubarPortal` | Renders content in a portal | `container` |
| `MenubarContent` | Dropdown panel for a menu | `align` (default: `"start"`), `alignOffset` (default: `-4`), `sideOffset` (default: `0`), `className` |
| `MenubarItem` | Clickable menu item | `inset`, `disabled`, `onSelect`, `className` |
| `MenubarCheckboxItem` | Item with `✓` indicator | `checked`, `onCheckedChange`, `disabled`, `className` |
| `MenubarRadioGroup` | Radio group container | `value`, `onValueChange` |
| `MenubarRadioItem` | Item with `●` indicator | `value`, `disabled`, `className` |
| `MenubarLabel` | Non-interactive section label | `inset`, `className` |
| `MenubarSeparator` | Horizontal rule between sections | `className` |
| `MenubarShortcut` | Right-aligned shortcut hint | `className` |
| `MenubarGroup` | Groups items for accessibility | — |
| `MenubarSub` | Sub-menu root | `open`, `onOpenChange`, `defaultOpen` |
| `MenubarSubTrigger` | Item that opens a sub-menu | `inset`, `className` |
| `MenubarSubContent` | Sub-menu floating panel | `className` |

## Notes

Built on [Radix UI Menubar](https://www.radix-ui.com/primitives/docs/components/menubar). The key structural difference from Dropdown Menu is the two-level root: `Menubar` (the horizontal bar) contains multiple `MenubarMenu` elements, each with its own `MenubarTrigger` and `MenubarContent`.

`MenubarTrigger` uses both `data-[state=open]:` and `focus-visible:` for inversion — the open state keeps the trigger highlighted while its dropdown is showing. Arrow keys move between bar items when a menu is open.

Items highlight via `data-[highlighted]:bg-foreground data-[highlighted]:text-background`. No `hover:` variants. Content fades in/out via `termcn-fade` / `termcn-fade-out` (≤150ms).
