# Skeleton

Terminal-style loading placeholder that pulses to indicate pending content. Renders a bordered block with `animate-pulse` and a muted background level. Shape is fully controlled via `className`.

## Installation

<InstallTabs pkg="@termcn/skeleton" />

## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton"

export default function SkeletonDemo() {
  return <Skeleton className="h-4 w-48" />
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Controls dimensions, additional styling |
| ...rest | `ComponentProps<"div">` | — | All standard `<div>` props |

## Notes

- Skeleton has no intrinsic size — always pass `h-*` and `w-*` via `className`.
- The border uses `border-border/40` (40% opacity) to keep placeholders visually lighter than real content.
- Background is `bg-background2` (`--background2`, Catppuccin Surface 0) — one level above the main background.
- `animate-pulse` is Tailwind's built-in opacity cycle; no custom keyframes are added.
