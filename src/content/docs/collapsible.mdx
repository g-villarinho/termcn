# Collapsible

Terminal-style expandable panel built on Radix UI. Single collapsible section with a trigger button that shows `▸` (closed) or `▾` (open). Open state adds a border-bottom to the trigger and shifts to `background1`. Content fades in/out at 150ms. Focus inverts foreground/background — no hover.

## Installation

<InstallTabs pkg="@termcn/collapsible" />

## Usage

```tsx
import {
  Collapsible,
  CollapsibleTrigger,
  CollapsibleContent,
} from "@/components/ui/collapsible"

export default function CollapsibleDemo() {
  return (
    <Collapsible>
      <CollapsibleTrigger>Toggle section</CollapsibleTrigger>
      <CollapsibleContent>Hidden content revealed on expand.</CollapsibleContent>
    </Collapsible>
  )
}
```

## Props

### Collapsible

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | — | Controlled open state |
| `defaultOpen` | `boolean` | `false` | Initial open state (uncontrolled) |
| `onOpenChange` | `(open: boolean) => void` | — | Callback when open state changes |
| `disabled` | `boolean` | `false` | Prevent trigger interaction |
| `className` | `string` | — | Additional Tailwind classes |

### CollapsibleTrigger

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional Tailwind classes |
| `children` | `ReactNode` | — | Trigger label content |

### CollapsibleContent

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional Tailwind classes |
| `children` | `ReactNode` | — | Panel content shown when open |

## Notes

- Built on [`@radix-ui/react-collapsible`](https://www.radix-ui.com/primitives/docs/components/collapsible) — inherits keyboard accessibility and ARIA attributes.
- Chevron (`▸` / `▾`) is rendered by the component using `group-data-[state=open]` class toggling — no extra icon library needed.
- Open trigger gains `border-b border-border bg-background1` to visually separate from content.
- Content animates with `termcn-fade` / `termcn-fade-out` keyframes at 150ms — defined in `src/index.css`.
- Focus uses full foreground/background inversion (`focus-visible:bg-foreground focus-visible:text-background`) — no hover states.
- Unlike `Accordion`, `Collapsible` manages a single panel. Use `Accordion` for multi-section patterns.
