# Context Menu

Terminal-style right-click context menu. `ContextMenuTrigger` wraps any element and listens for right-click (or long-press on touch); content appears at the cursor position with a 150ms fade.

Same item types as Dropdown Menu — checkbox items (`✓`), radio groups (`●`), sub-menus, shortcuts, labels, separators, and inset items. All navigation is keyboard-driven via Radix.

## Installation

<InstallTabs pkg="@termcn/context-menu" />

## Usage

```tsx
import {
  ContextMenu,
  ContextMenuTrigger,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuSeparator,
} from "@/components/ui/context-menu"

export default function Demo() {
  return (
    <ContextMenu>
      <ContextMenuTrigger>
        <div className="border border-border p-8 text-sm text-muted-foreground">
          Right-click here
        </div>
      </ContextMenuTrigger>
      <ContextMenuContent>
        <ContextMenuItem>Item</ContextMenuItem>
        <ContextMenuSeparator />
        <ContextMenuItem>Another item</ContextMenuItem>
      </ContextMenuContent>
    </ContextMenu>
  )
}
```

## Props

| Sub-component | Purpose | Key props |
|---|---|---|
| `ContextMenu` | Root state provider | `onOpenChange`, `modal` |
| `ContextMenuTrigger` | Listens for right-click; wraps any element | `asChild`, `disabled` |
| `ContextMenuPortal` | Renders content in a portal | `container` |
| `ContextMenuContent` | Floating menu panel at cursor position | `alignOffset`, `className` |
| `ContextMenuItem` | Clickable menu item | `inset`, `disabled`, `onSelect`, `className` |
| `ContextMenuCheckboxItem` | Item with `✓` indicator | `checked`, `onCheckedChange`, `disabled`, `className` |
| `ContextMenuRadioGroup` | Radio group container | `value`, `onValueChange` |
| `ContextMenuRadioItem` | Item with `●` indicator | `value`, `disabled`, `className` |
| `ContextMenuLabel` | Non-interactive section label | `inset`, `className` |
| `ContextMenuSeparator` | Horizontal rule between sections | `className` |
| `ContextMenuShortcut` | Right-aligned shortcut hint | `className` |
| `ContextMenuGroup` | Groups items for accessibility | — |
| `ContextMenuSub` | Sub-menu root | `open`, `onOpenChange`, `defaultOpen` |
| `ContextMenuSubTrigger` | Item that opens a sub-menu | `inset`, `className` |
| `ContextMenuSubContent` | Sub-menu floating panel | `className` |

## Notes

Built on [Radix UI Context Menu](https://www.radix-ui.com/primitives/docs/components/context-menu). The key difference from `DropdownMenu` is that `ContextMenuTrigger` wraps an arbitrary element and listens for `contextmenu` events (right-click / long-press) rather than a button click. Content is positioned at the cursor rather than relative to the trigger bounds.

All keyboard navigation (arrow keys, Enter, Escape) is handled by Radix. Items highlight via `data-[highlighted]:bg-foreground data-[highlighted]:text-background`. No `hover:` variants are used. Content fades in via `termcn-fade` (≤150ms).
