# Breadcrumb

Terminal-style breadcrumb navigation trail. Composite structure: `nav > ol > li` items. Links use focus-visible inversion. Current page has solid border background. ChevronRight icon as default separator.

Follows TUI aesthetic: interaction via focus only, monospace typography, sharp edges, depth via background levels.

## Installation

<InstallTabs pkg="@termcn/breadcrumb" />

## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbList,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbPage,
  BreadcrumbSeparator,
  BreadcrumbEllipsis,
} from "@/components/ui/breadcrumb"

export default function BreadcrumbDemo() {
  return (
    <Breadcrumb>
      <BreadcrumbList>
        <BreadcrumbItem>
          <BreadcrumbLink href="/">Home</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbPage>Current</BreadcrumbPage>
        </BreadcrumbItem>
      </BreadcrumbList>
    </Breadcrumb>
  )
}
```

### With asChild links

Use `asChild` on `BreadcrumbLink` to render a framework router link (e.g. Next.js `Link`).

```tsx

    <BreadcrumbItem>
      <BreadcrumbLink asChild>

    </BreadcrumbItem>
```

## Props

| Sub-component | Props | Description |
|---------------|-------|-------------|
| `Breadcrumb` | `className`, `...ComponentProps<"nav">` | Root `<nav aria-label="breadcrumb">` |
| `BreadcrumbList` | `className`, `...ComponentProps<"ol">` | Flex `<ol>` container |
| `BreadcrumbItem` | `className`, `...ComponentProps<"li">` | Inline-flex `<li>` wrapper |
| `BreadcrumbLink` | `asChild`, `className`, `...ComponentProps<"a">` | Anchor with focus-inversion; `asChild` delegates to Radix Slot |
| `BreadcrumbPage` | `className`, `...ComponentProps<"span">` | Current page marker (`aria-current="page"`, non-interactive) |
| `BreadcrumbSeparator` | `children`, `className`, `...ComponentProps<"li">` | Separator `<li>`; defaults to `ChevronRight` icon |
| `BreadcrumbEllipsis` | `className`, `...ComponentProps<"span">` | Collapsed overflow indicator (`MoreHorizontal` icon) |

## Notes

- `BreadcrumbLink` uses `focus-visible:` inversion (bg-foreground / text-background) — no hover state.
- `BreadcrumbPage` renders as `<span role="link" aria-disabled="true">` — visually distinct but not interactive.
- `BreadcrumbSeparator` and `BreadcrumbEllipsis` are `aria-hidden="true"` to keep screen reader output clean.
- Pass `asChild` to `BreadcrumbLink` when using a client-side router — the inner element receives all anchor props.
