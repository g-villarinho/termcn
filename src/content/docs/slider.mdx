# Slider

Terminal-style range slider. Horizontal track with `bg-primary` fill range, square thumb with focus-visible inversion, bordered track on `bg-background1`. Supports single value, range (multiple thumbs), custom min/max/step, disabled state, and vertical orientation.

## Installation

<InstallTabs pkg="@termcn/slider" />

## Usage

```tsx
import { Slider } from "@/components/ui/slider"

export default function SliderDemo() {
  return <Slider defaultValue={[40]} max={100} step={1} />
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `defaultValue` | `number[]` | `[min]` | Uncontrolled initial value(s) |
| `value` | `number[]` | — | Controlled value(s) |
| `min` | `number` | `0` | Minimum value |
| `max` | `number` | `100` | Maximum value |
| `step` | `number` | `1` | Increment between values |
| `onValueChange` | `(value: number[]) => void` | — | Callback on value change |
| `orientation` | `"horizontal"` \| `"vertical"` | `"horizontal"` | Slider axis |
| `disabled` | `boolean` | `false` | Disable interaction; mutes thumb to `foreground2`/`background2` |
| `className` | `string` | — | Additional Tailwind classes |
| ...rest | `ComponentProps<Slider.Root>` | — | All Radix Slider root props |

## Notes

- `value` and `defaultValue` are both `number[]` — pass a single-element array for a single thumb, two elements for a range.
- The range fill (`bg-primary`) starts from the track origin for single thumbs; for ranges, it spans between the two thumb positions.
- The vertical slider has a fixed height of `h-32` (`data-[orientation=vertical]:h-32`) by default; override with a `className` height utility.
- Disabled state uses `border-foreground2 bg-background2` on the thumb (not `opacity`) — consistent with the terminal dim-text convention.
- Focus state inverts the thumb: `bg-primary border-primary` with `ring-1 ring-ring`.
