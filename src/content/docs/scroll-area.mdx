# Scroll Area

Terminal-style scrollable container with custom scrollbar. Radix ScrollArea wrapper with a focus-visible viewport ring and a blocky, borderless-thumb scrollbar — no rounded corners, no shadows.

The scrollbar uses `bg-border/80` for the thumb with an inset border overlay, matching the terminal aesthetic of visible structure without softness.

## Installation

<InstallTabs pkg="@termcn/scroll-area" />

## Usage

```tsx
import { ScrollArea, ScrollBar } from "@/components/ui/scroll-area"

export default function ScrollAreaDemo() {
  return (
    <ScrollArea className="h-48 w-full">
      <div className="p-4">Long content here...</div>
    </ScrollArea>
  )
}
```

## Props

### ScrollArea

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional Tailwind classes |
| `children` | `ReactNode` | — | Scrollable content |
| ...rest | `ComponentProps<ScrollArea.Root>` | — | All Radix ScrollArea root props |

### ScrollBar

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `"vertical"` \| `"horizontal"` | `"vertical"` | Scrollbar axis |
| `className` | `string` | — | Additional Tailwind classes |
| ...rest | `ComponentProps<ScrollArea.Scrollbar>` | — | All Radix ScrollAreaScrollbar props |

## Notes

- `ScrollArea` always renders a vertical `ScrollBar` by default. Add `<ScrollBar orientation="horizontal" />` as a child for horizontal scrolling.
- The viewport has a `focus-visible:ring-1 focus-visible:ring-ring` outline for keyboard navigation.
- Scrollbar thumb is square (no border-radius) with a semi-transparent border overlay — no `hover:` state per design constraints.
- Corner between both scrollbars renders as `bg-background1`.
