# Textarea

Terminal-style multiline text input with auto-sizing content, sharp edges, and focus-only interaction.

Follows TUI aesthetic: no hover states, monospace typography, muted background depth, destructive ring on invalid.

## Installation

<InstallTabs pkg="@termcn/textarea" />

## Usage

```tsx
import { Textarea } from "@/components/ui/textarea"

export default function TextareaDemo() {
  return <Textarea placeholder="Type here..." />
}
```

### Error state

Use `aria-invalid="true"` to signal a validation error. The focus ring switches to `--destructive`.

<Preview>
  <div className="flex flex-col gap-4 w-full max-w-sm">

  </div>
</Preview>

```tsx

```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `placeholder` | `string` | — | Placeholder text |
| `disabled` | `boolean` | `false` | Disable the textarea |
| `aria-invalid` | `"true"` \| `"false"` | — | Mark field as invalid (switches to destructive ring) |
| `className` | `string` | — | Additional Tailwind classes |
| ...rest | `ComponentProps<"textarea">` | — | All standard `<textarea>` props |
