# Combobox

Terminal-style fzf-inspired searchable picker. Opens a floating popover with a `> ` search prompt and a keyboard-navigable Command list. Filter-as-you-type via cmdk fuzzy matching. Selected item shows a ✓ indicator with Vim-style background inversion.

Built on Popover + Command + Button.

## Installation

<InstallTabs pkg="@termcn/combobox" />

## Usage

```tsx
import { Combobox } from "@/components/ui/combobox"
import type { ComboboxOption } from "@/components/ui/combobox"

const options: ComboboxOption[] = [
  { value: "neovim", label: "Neovim" },
  { value: "vim", label: "Vim" },
  { value: "emacs", label: "Emacs" },
]

export default function ComboboxDemo() {
  const [value, setValue] = React.useState("")

  return (
    <Combobox
      options={options}
      value={value}
      onValueChange={setValue}
    />
  )
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `options` | `ComboboxOption[]` | — | Array of selectable items |
| `value` | `string` | — | Controlled selected value |
| `onValueChange` | `(value: string) => void` | — | Called when selection changes |
| `placeholder` | `string` | `"select option..."` | Text shown when no value selected |
| `searchPlaceholder` | `string` | `"search..."` | Placeholder inside the search input |
| `emptyText` | `string` | `"-- no results --"` | Text shown when search yields no matches |
| `disabled` | `boolean` | `false` | Disable the entire combobox |
| `className` | `string` | — | Additional classes on the trigger button |

### ComboboxOption type

```ts
interface ComboboxOption {
  value: string
  label: string
  disabled?: boolean
}
```

## Notes

- Composes **Popover** (floating container) + **Command** (keyboard list with `CommandInput`) + **Button** (trigger).
- Filtering is handled by cmdk's built-in fuzzy matching against `option.label`.
- Selecting an already-selected item toggles it off (sets value to `""`).
- For a picker without search, use [Select](/docs/select) instead.
- Arrow-key navigation and `Enter` selection are provided by the cmdk `Command` primitive.
- Selected item shows a `✓` indicator; active item uses Vim-style foreground/background inversion.
