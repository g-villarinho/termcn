# Popover

Terminal-style floating popover with fade animation, position control, and no shadow/radius. Content floats at 4px offset with border and elevated background level.

Built on Radix Popover. 72px max-width, depth via `--popover` background and border only. Auto-positioning via Radix collision detection.

## Installation

<InstallTabs pkg="@termcn/popover" />

## Usage

```tsx
import { Popover, PopoverTrigger, PopoverContent } from "@/components/ui/popover"
import { Button } from "@/components/ui/button"

export default function PopoverDemo() {
  return (
    <Popover>
      <PopoverTrigger asChild>
        <Button>Open Popover</Button>
      </PopoverTrigger>
      <PopoverContent>Popover content goes here.</PopoverContent>
    </Popover>
  )
}
```

## Props

| Component | Prop | Type | Default | Description |
|-----------|------|------|---------|-------------|
| `Popover` | — | Radix Root | — | Popover root container |
| `PopoverTrigger` | — | Radix Trigger | — | Button/element that opens popover |
| `PopoverAnchor` | — | Radix Anchor | — | Optional: position reference (defaults to trigger) |
| `PopoverContent` | `align` | `center` \| `start` \| `end` | `center` | Horizontal alignment relative to trigger |
| `PopoverContent` | `sideOffset` | `number` | `4` | Distance in px from trigger/anchor |
| `PopoverContent` | `className` | `string` | — | Additional Tailwind classes |
| `PopoverContent` | ...rest | Radix Content props | — | All standard Radix Content props |

## Notes

- Built on **Radix Popover** — provides positioning, collision detection, and focus management
- **Animations**: Fade-in (150ms ease-out) and fade-out on close
- **Collision detection**: Auto-repositions if popover would extend off-screen
- **Keyboard**: <kbd>Esc</kbd> closes popover; <kbd>Tab</kbd> traps focus within
- **Trigger click**: Clicking trigger again toggles popover (open/close)
- **Outside click**: Clicking outside popover closes it
- **Focus management**: Focus returns to trigger when closed
- **Background**: Uses `--popover` CSS variable (elevated level, darker than card)
