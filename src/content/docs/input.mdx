# Input

Terminal-style text input: borderless filled surface that lightens on focus with a ring, no radius, and semantic error states via `aria-invalid`.

Follows TUI aesthetic: no border, sharp edges, monospace font, focus-based interaction, minimal visual noise.

## Installation

<InstallTabs pkg="@termcn/input" />

## Usage

```tsx
import { Input } from "@/components/ui/input"

export default function InputDemo() {
  return <Input placeholder="Enter text..." />
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `type` | `string` | `text` | HTML input type (text, email, password, file, etc.) |
| `placeholder` | `string` | — | Placeholder text |
| `disabled` | `boolean` | `false` | Disable input |
| `aria-invalid` | `boolean` \| `"true"` \| `"false"` | — | Mark input as invalid (shows destructive focus ring) |
| `className` | `string` | — | Additional Tailwind classes |
| ...rest | `ComponentProps<"input">` | — | All standard `<input>` props |

## Notes

- Uses `aria-invalid` for semantic error states, not a separate `error` prop.
- File input text is styled with `file:` pseudo-element selectors.
- Focus ring appears on `focus-visible` (not `focus`), matching keyboard-first design.
