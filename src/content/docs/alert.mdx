# Alert

Terminal-style alert banner composed of a container, title, and description. Five semantic variants (default, info, success, warning, destructive). Optional SVG icon slot via CSS grid layout — when an `<svg>` is present as a direct child, the grid switches to a two-column layout with the icon in the left slot.

## Installation

<InstallTabs pkg="@termcn/alert" />

## Usage

```tsx
import { Alert, AlertTitle, AlertDescription } from "@/components/ui/alert"

export default function AlertDemo() {
  return (
    <Alert>
      <AlertTitle>Heads up</AlertTitle>
      <AlertDescription>Something happened that you should know about.</AlertDescription>
    </Alert>
  )
}
```

## Notes

- The grid switches automatically between single-column and two-column layout based on whether an SVG is a direct child — no extra prop needed.
- `role="alert"` is set on the container for screen reader announcements.
- `AlertTitle` and `AlertDescription` each use `col-start-2` to always align to the content column, regardless of whether an icon is present.
