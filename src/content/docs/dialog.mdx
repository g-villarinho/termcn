# Dialog

Terminal-style modal dialog built on Radix Dialog. Centered overlay (`max-w-lg`) with a translucent backdrop, monospace typography, and a bracket-style `[x]` close button in the top-right corner.

Follows TUI aesthetic: title prefixed with `▍`, sharp edges, no shadow, and a discrete 150ms opacity fade on open/close. Interaction via focus only.

## Installation

<InstallTabs pkg="@termcn/dialog" />

## Usage

```tsx
import {
  Dialog,
  DialogTrigger,
  DialogContent,
  DialogHeader,
  DialogTitle,
  DialogDescription,
} from "@/components/ui/dialog"

export default function DialogDemo() {
  return (
    <Dialog>
      <DialogTrigger asChild>
        <Button>Open</Button>
      </DialogTrigger>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>Title</DialogTitle>
          <DialogDescription>Description text.</DialogDescription>
        </DialogHeader>
      </DialogContent>
    </Dialog>
  )
}
```

### Controlled

Drive open state yourself with `open` and `onOpenChange` on the `Dialog` root — useful for non-dismissable flows where you decide when the dialog may close.

```tsx
const [open, setOpen] = React.useState(false)

return (
  <Dialog open={open} onOpenChange={setOpen}>
    <DialogTrigger asChild>
      <Button>Open</Button>
    </DialogTrigger>
    <DialogContent
      onInteractOutside={(e) => e.preventDefault()}
      onEscapeKeyDown={(e) => e.preventDefault()}
    >
      <DialogHeader>
        <DialogTitle>Confirm before leaving</DialogTitle>
        <DialogDescription>Outside clicks are ignored.</DialogDescription>
      </DialogHeader>
      <DialogFooter>
        <Button variant="primary" onClick={() => setOpen(false)}>
          Done
        </Button>
      </DialogFooter>
    </DialogContent>
  </Dialog>
)
```

## Props

| Sub-component | Purpose | Key props |
|------|---------|-----------|
| `Dialog` | Root state provider | `open`, `defaultOpen`, `onOpenChange`, `modal` |
| `DialogTrigger` | Element that opens the dialog | `asChild` |
| `DialogContent` | Centered panel; renders overlay + `[x]` close | `className`, `onInteractOutside`, `onEscapeKeyDown` |
| `DialogOverlay` | Backdrop layer (auto-rendered by content) | `className` |
| `DialogHeader` | Vertical title/description group | `className` |
| `DialogTitle` | Accessible title with `▍` prefix | `className` |
| `DialogDescription` | Muted description text | `className` |
| `DialogFooter` | Action row (right-aligned on `sm`+) | `className` |
| `DialogClose` | Closes the dialog | `asChild` |
| `DialogPortal` | Portals content to `document.body` | — |

All sub-components forward their standard [Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog) props plus `className`.

## Notes

- Built on `@radix-ui/react-dialog`. `DialogContent` automatically renders `DialogOverlay`, the portal, and the bracket `[x]` close button — you do not need to add them manually.
- Animation is a single 150ms opacity fade (`termcn-fade` / `termcn-fade-out`) on both overlay and content — no scale, slide, or spring.
- Accessibility is handled by Radix: focus is trapped while open, `Esc` closes, the trigger is restored focus on close, and `DialogTitle` / `DialogDescription` are wired to `aria-labelledby` / `aria-describedby`. Always include a `DialogTitle` (use the `sr-only` class to hide it visually if needed).
- The close button uses `focus-visible:` inversion (`bg-foreground text-background`) rather than hover.
