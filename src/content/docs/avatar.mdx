# Avatar

Terminal-style user avatar built on Radix Avatar. Handles image loading with an automatic fallback to centered initials on a secondary background. Three sizes (sm, default, lg). Sharp edges, monospace font, border on all sides.

## Installation

<InstallTabs pkg="@termcn/avatar" />

## Usage

```tsx
import { Avatar, AvatarImage, AvatarFallback } from "@/components/ui/avatar"

export default function AvatarDemo() {
  return (
    <Avatar>
      <AvatarImage src="https://github.com/gbvillarinho.png" alt="Gabriel Villarinho" />
      <AvatarFallback>GV</AvatarFallback>
    </Avatar>
  )
}
```

## Props

### Avatar

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `sm` \| `default` \| `lg` | `default` | Controls width, height, and font size (`8/10/12` rem units) |
| `className` | `string` | — | Additional Tailwind classes |
| ...rest | Radix `AvatarRoot` props | — | All Radix Avatar.Root props |

### AvatarImage

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `src` | `string` | — | Image URL |
| `alt` | `string` | — | Alt text for the image (required for accessibility) |
| `className` | `string` | — | Additional Tailwind classes |
| ...rest | Radix `AvatarImage` props | — | All Radix Avatar.Image props |

### AvatarFallback

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | — | Content shown when image is absent or fails (typically 1-2 initials) |
| `className` | `string` | — | Additional Tailwind classes |
| ...rest | Radix `AvatarFallback` props | — | All Radix Avatar.Fallback props |

## Notes

- Radix Avatar handles the loading state automatically — `AvatarFallback` is shown during image load and on error, with no extra state management needed.
- `"use client"` is required at the top of the source file because Radix Avatar uses browser APIs for image load detection.
- Always provide `alt` text on `AvatarImage` for screen reader accessibility.
