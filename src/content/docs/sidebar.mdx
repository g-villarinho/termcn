# Sidebar

The flagship layout component. Terminal-style collapsible sidebar with navigation groups, responsive mobile overlay, and React Context state management.

Desktop: fixed sidebar panel (18rem expanded, 3.5rem icon-only) with inset content area that responds to sidebar width. Mobile: Sheet-based overlay triggered by the same `SidebarTrigger`. Composed from Button, Input, and Sheet primitives.

## Architecture

`SidebarProvider` establishes a React Context that all sub-components read via the `useSidebar` hook. The context tracks expanded/collapsed state, mobile open state, and the `isMobile` flag (breakpoint at 768px).

```
SidebarProvider          ← context root, sets CSS vars
  ├── Sidebar            ← the panel (desktop: fixed aside, mobile: Sheet)
  │   ├── SidebarHeader  ← branding / search row
  │   ├── SidebarContent ← scrollable body
  │   │   └── SidebarGroup > SidebarMenu > SidebarMenuItem > SidebarMenuButton
  │   └── SidebarFooter  ← user profile / actions
  ├── SidebarRail        ← click-to-toggle border strip (optional)
  └── SidebarInset       ← main content area (flex-1, adjusts to sidebar width)
        └── SidebarTrigger  ← toggle button (can live anywhere inside Provider)
```

`SidebarTrigger` can be placed anywhere inside `SidebarProvider` — typically inside `SidebarInset`'s top bar.

## Usage

```tsx
import {
  SidebarProvider,
  Sidebar,
  SidebarTrigger,
  SidebarInset,
  SidebarHeader,
  SidebarContent,
  SidebarFooter,
  SidebarGroup,
  SidebarGroupLabel,
  SidebarGroupContent,
  SidebarMenu,
  SidebarMenuItem,
  SidebarMenuButton,
} from "@/components/ui/sidebar"

export default function AppLayout({ children }: { children: React.ReactNode }) {
  return (
    <SidebarProvider>
      <Sidebar>
        <SidebarHeader>
          <span className="font-mono text-sm text-foreground">~/project</span>
        </SidebarHeader>
        <SidebarContent>
          <SidebarGroup>
            <SidebarGroupLabel>Navigation</SidebarGroupLabel>
            <SidebarGroupContent>
              <SidebarMenu>
                <SidebarMenuItem>
                  <SidebarMenuButton isActive>Dashboard</SidebarMenuButton>
                </SidebarMenuItem>
                <SidebarMenuItem>
                  <SidebarMenuButton>Settings</SidebarMenuButton>
                </SidebarMenuItem>
              </SidebarMenu>
            </SidebarGroupContent>
          </SidebarGroup>
        </SidebarContent>
        <SidebarFooter>
          <span className="font-mono text-xs text-foreground2">user@host</span>
        </SidebarFooter>
      </Sidebar>
      <SidebarInset>
        <header className="flex h-10 items-center gap-2 border-b border-border px-3">
          <SidebarTrigger />
          <span className="font-mono text-xs text-foreground1">Dashboard</span>
        </header>
        <main className="p-4">{children}</main>
      </SidebarInset>
    </SidebarProvider>
  )
}
```

### Collapsible: `offcanvas` mode

`collapsible="offcanvas"` slides the sidebar fully off-screen when collapsed. The content area expands to fill the full width.

```tsx
<SidebarProvider>
  <Sidebar collapsible="offcanvas">
    {/* ... */}
  </Sidebar>
  <SidebarInset>
    <SidebarTrigger />
    {/* content expands to full width when sidebar is off-screen */}
  </SidebarInset>
</SidebarProvider>
```

### Non-collapsible sidebar

`collapsible="none"` renders a permanent `<aside>` with no toggle capability.

```tsx
<SidebarProvider>
  <Sidebar collapsible="none">
    {/* always visible, no trigger needed */}
  </Sidebar>
  <SidebarInset>{/* ... */}</SidebarInset>
</SidebarProvider>
```

### Mobile Responsive

On screens narrower than 768px, `Sidebar` automatically renders as a `Sheet` overlay. `SidebarTrigger` opens/closes the sheet. No additional code required — responsiveness is built in.

```tsx
// Same code works on desktop (collapsible panel) and mobile (Sheet overlay).
<SidebarProvider>
  <Sidebar collapsible="icon">
    {/* ... */}
  </Sidebar>
  <SidebarInset>
    {/* SidebarTrigger opens Sheet on mobile, toggles panel on desktop */}
    <SidebarTrigger />
  </SidebarInset>
</SidebarProvider>
```

### Controlled State

Pass `open` and `onOpenChange` to `SidebarProvider` for controlled usage.

```tsx
const [open, setOpen] = React.useState(true)

<SidebarProvider open={open} onOpenChange={setOpen}>
  <Sidebar>{/* ... */}</Sidebar>
  <SidebarInset>
    <button onClick={() => setOpen(o => !o)}>Toggle</button>
  </SidebarInset>
</SidebarProvider>
```

### useSidebar Hook

Access sidebar state from any component inside `SidebarProvider`.

```tsx
import { useSidebar } from "@/components/ui/sidebar"

function StatusBar() {
  const { state, isMobile, toggleSidebar } = useSidebar()

  return (
    <div className="font-mono text-xs text-foreground2">
      sidebar: {state} {isMobile && "(mobile)"}
    </div>
  )
}
```

## Sub-components

| Component | Element | Role |
|-----------|---------|------|
| `SidebarProvider` | `div` | Context root. Sets CSS vars, wraps layout in flex. |
| `Sidebar` | `aside` / `Sheet` | The panel. Desktop: fixed positioned aside. Mobile: Sheet overlay. |
| `SidebarTrigger` | `Button` | Toggles sidebar. Renders `▸` / `▾` glyph. |
| `SidebarInset` | `main` | Content area. `flex-1`, expands as sidebar collapses. |
| `SidebarHeader` | `div` | Top zone with `border-b`. |
| `SidebarFooter` | `div` | Bottom zone with `border-t`, `mt-auto`. |
| `SidebarContent` | `div` | Scrollable body between header and footer. |
| `SidebarGroup` | `section` | Logical grouping with `px-3` padding. |
| `SidebarGroupLabel` | `div` | Muted label text for a group. Hidden in icon mode. |
| `SidebarGroupAction` | `button` | Absolute-positioned action at group top-right. Hidden in icon mode. |
| `SidebarGroupContent` | `div` | Container for a group's menu. |
| `SidebarMenu` | `ul` | Ordered list of navigation items. |
| `SidebarMenuItem` | `li` | Single nav item. Relative-positioned for badge/action placement. |
| `SidebarMenuButton` | `button` | The interactive nav row. Supports `isActive`, `asChild`, `size`. |
| `SidebarMenuAction` | `button` | Absolute-positioned item-level action. Hidden in icon mode. |
| `SidebarMenuBadge` | `div` | Numeric badge at item right. Hidden in icon mode. |
| `SidebarSeparator` | `div` | 1px horizontal rule. `mx-3`, `bg-border`. |
| `SidebarInput` | `Input` | Search input sized for sidebar (`h-8 text-xs`). |
| `SidebarRail` | `button` | Thin collapse-toggle strip on sidebar edge. |

## useSidebar Hook

Returns the sidebar context value. Throws if called outside `SidebarProvider`.

| Property | Type | Description |
|----------|------|-------------|
| `state` | `"expanded" \| "collapsed"` | Current desktop sidebar state |
| `open` | `boolean` | `true` when sidebar is open (desktop) |
| `setOpen` | `(open: boolean) => void` | Set sidebar open state |
| `openMobile` | `boolean` | `true` when mobile Sheet is open |
| `setOpenMobile` | `(open: boolean) => void` | Set mobile sheet open state |
| `isMobile` | `boolean` | `true` when viewport < 768px |
| `toggleSidebar` | `() => void` | Toggles desktop sidebar or mobile sheet depending on `isMobile` |

## Props

### SidebarProvider

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `defaultOpen` | `boolean` | `true` | Initial open state (uncontrolled) |

## Notes

**CSS variables** — `SidebarProvider` sets `--sidebar-width: 18rem` and `--sidebar-width-icon: 3.5rem` inline on the wrapper div. Override via `style` prop or the `className` prop with CSS-in-JS if needed.

**Mobile breakpoint** — `useIsMobile()` listens to `(max-width: 767px)` via `matchMedia`. At 768px and above, the panel renders. Below, the Sheet renders. The `SidebarTrigger` behaves accordingly — `toggleSidebar()` calls `setOpen` on desktop and `setOpenMobile` on mobile.

**Icon mode** — when `collapsible="icon"` and sidebar is collapsed, these slots are hidden via CSS attribute selectors on the `aside`: `sidebar-group-label`, `sidebar-group-action`, `sidebar-menu-action`, `sidebar-menu-badge`. `sidebar-menu-button` gets `justify-center px-0`.

**Context boundary** — all sub-components call `useSidebar()` internally. `useSidebar` throws if rendered outside a `SidebarProvider`. The hook is also exported for custom components that need to read or drive sidebar state.

**Animation** — collapse uses `transition-[width] duration-150 ease-out` (icon mode) or `transition-[transform] duration-150 ease-out` (offcanvas mode). Both are ≤150ms per the terminal aesthetic constraint.
