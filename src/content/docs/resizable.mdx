# Resizable

Terminal-style resizable panel layout built on [react-resizable-panels](https://github.com/bvaughn/react-resizable-panels). The handle renders as a 1px border line with an invisible touch area. Pass `withHandle` to show a `:::` gripper. Focus-visible ring on the handle for keyboard resizing.

## Installation

<InstallTabs pkg="@termcn/resizable" />

## Usage

```tsx
import {
  ResizablePanelGroup,
  ResizablePanel,
  ResizableHandle,
} from "@/components/ui/resizable"

export default function ResizableDemo() {
  return (
    <ResizablePanelGroup direction="horizontal">
      <ResizablePanel defaultSize={50}>Left</ResizablePanel>
      <ResizableHandle />
      <ResizablePanel defaultSize={50}>Right</ResizablePanel>
    </ResizablePanelGroup>
  )
}
```

## Props

| Sub-component | Props | Description |
|---------------|-------|-------------|
| `ResizablePanelGroup` | `direction`, `className`, `...GroupProps` | Root flex container; sets axis |
| `ResizablePanel` | `defaultSize`, `minSize`, `maxSize`, `className`, `...PanelProps` | Individual panel |
| `ResizableHandle` | `withHandle`, `className`, `...SeparatorProps` | Drag handle; optional `:::` gripper |

### ResizablePanelGroup props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `direction` | `"horizontal"` \| `"vertical"` | — | **Required.** Panel layout axis |
| `className` | `string` | — | Additional Tailwind classes |

### ResizablePanel props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `defaultSize` | `number` | — | Initial size as percentage of group |
| `minSize` | `number` | — | Minimum size percentage |
| `maxSize` | `number` | — | Maximum size percentage |
| `className` | `string` | — | Additional Tailwind classes |

### ResizableHandle props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `withHandle` | `boolean` | `false` | Show `:::` gripper on the handle |
| `className` | `string` | — | Additional Tailwind classes |

## Notes

- Built on [react-resizable-panels](https://github.com/bvaughn/react-resizable-panels) — drag, touch, and keyboard resizing are handled by the library.
- The handle has an invisible `after:` pseudo-element with a wider touch area (`w-4`) to improve drag ergonomics without changing the visual border width.
- Keyboard resizing: focus the handle and use arrow keys. `focus-visible:ring-1` makes the focused handle visible.
- `ResizablePanelGroup` needs an explicit height when used with `direction="vertical"` — add `className="h-48"` or a parent that constrains height.
- `defaultSize` values across sibling panels should sum to 100.
