# Card

Terminal-style content container. Bordered box with optional header (bottom-border separator), content body, and footer (top-border separator). Title uses `▍` prefix in primary color. All sections are monospace throughout.

## Installation

<InstallTabs pkg="@termcn/card" />

## Usage

```tsx
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardContent,
  CardFooter,
} from "@/components/ui/card"

export default function CardDemo() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>Title</CardTitle>
        <CardDescription>A short description.</CardDescription>
      </CardHeader>
      <CardContent>Content goes here.</CardContent>
      <CardFooter>Footer</CardFooter>
    </Card>
  )
}
```

## Notes

- `CardTitle` renders a `▍` block-cursor prefix via CSS `before:content-['▍']` in `text-primary`.
- `CardHeader` and `CardFooter` use `border-b` / `border-t` to create TUI box-separator lines.
- `CardDescription` is indented with `pl-4` to align under the title text past the `▍` prefix.
- No Radix primitives — pure React with `cn()` class merging.
