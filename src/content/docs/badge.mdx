# Badge

Terminal-style inline label for status, category, or metadata annotation. Supports 8 semantic color variants, 3 bracket styles, and `asChild` for polymorphic rendering.

Follows TUI aesthetic: sharp edges, focus-only interaction, monospace typography, Catppuccin Mocha tokens.

## Installation

<InstallTabs pkg="@termcn/badge" />

## Usage

```tsx
import { Badge } from "@/components/ui/badge"

export default function BadgeDemo() {
  return <Badge>label</Badge>
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `default` \| `primary` \| `secondary` \| `success` \| `warning` \| `destructive` \| `info` \| `ghost` | `default` | Color scheme using Catppuccin Mocha tokens |
| `bracket` | `square` \| `paren` \| `none` | `none` | Wraps label with `[…]`, `(…)`, or no brackets |
| `asChild` | `boolean` | `false` | Render as child element via Radix Slot |
| `className` | `string` | — | Additional Tailwind classes |
| ...rest | `ComponentProps<"span">` | — | All standard `<span>` props |

## Notes

- The `square` bracket style renders `[label]` via CSS `before`/`after` pseudo-elements — bracket characters are not in the DOM.
- `asChild` delegates rendering to the immediate child element; the child must accept a `className` prop.
- SVG icons nested directly inside `<Badge>` are auto-sized to `size-3` (12px) via the `[&_svg]:size-3` selector.
