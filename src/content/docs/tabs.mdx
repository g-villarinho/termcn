# Tabs

Terminal-style tabbed interface built on Radix Tabs. Horizontal tab bar with bottom border. Active tab gets foreground inversion (`bg-foreground text-background`). Tab triggers have right-border separators. Content area below.

Follows TUI aesthetic: interaction via focus only, monospace typography, sharp edges, depth via background levels.

## Installation

<InstallTabs pkg="@termcn/tabs" />

## Usage

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from "@/components/ui/tabs"

export default function TabsDemo() {
  return (
    <Tabs defaultValue="one">
      <TabsList>
        <TabsTrigger value="one">One</TabsTrigger>
        <TabsTrigger value="two">Two</TabsTrigger>
      </TabsList>
      <TabsContent value="one">Content for one.</TabsContent>
      <TabsContent value="two">Content for two.</TabsContent>
    </Tabs>
  )
}
```

### Controlled

Control the active tab programmatically with `value` and `onValueChange`.

```tsx
const [tab, setTab] = React.useState("one")

<Tabs value={tab} onValueChange={setTab}>
  <TabsList>
    <TabsTrigger value="one">One</TabsTrigger>
    <TabsTrigger value="two">Two</TabsTrigger>
  </TabsList>
  <TabsContent value="one">One</TabsContent>
  <TabsContent value="two">Two</TabsContent>
</Tabs>
```

## Props

| Sub-component | Props | Description |
|---------------|-------|-------------|
| `Tabs` | `defaultValue`, `value`, `onValueChange`, `className`, `...RadixTabsRoot` | Root container; wraps Radix `Tabs.Root` |
| `TabsList` | `className`, `...RadixTabsList` | Horizontal tab bar with bottom border |
| `TabsTrigger` | `value` (required), `disabled`, `className`, `...RadixTabsTrigger` | Individual tab button; active state inverts foreground |
| `TabsContent` | `value` (required), `className`, `...RadixTabsContent` | Panel shown when matching trigger is active |

### Tabs props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `defaultValue` | `string` | — | Initially selected tab (uncontrolled) |
| `value` | `string` | — | Controlled active tab value |
| `onValueChange` | `(value: string) => void` | — | Callback when active tab changes |
| `className` | `string` | — | Additional Tailwind classes |

### TabsTrigger props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | — | **Required.** Matches a `TabsContent` value |
| `disabled` | `boolean` | `false` | Prevents selection; renders in dim foreground |
| `className` | `string` | — | Additional Tailwind classes |

## Notes

- Active trigger state uses `data-[state=active]` — Radix sets this attribute automatically.
- `TabsTrigger` uses `focus-visible:` inversion matching the active state — keyboard navigation is visually consistent.
- The last `TabsTrigger` in the list has `last:border-r-0` to avoid a double-border at the list edge.
- `TabsContent` has `focus-visible:ring-1` for cases where the panel itself receives focus.
- Keyboard navigation follows Radix defaults: arrow keys move between triggers, `Home`/`End` jump to first/last.
