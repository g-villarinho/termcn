# Accordion

Terminal-style collapsible accordion built on Radix UI. Items separated by `border-b`. Trigger shows `▸` (closed) or `▾` (open) in primary color. Content indented with a left border. Focus inverts foreground/background — no hover.

## Installation

<InstallTabs pkg="@termcn/accordion" />

## Usage

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionTrigger,
  AccordionContent,
} from "@/components/ui/accordion"

export default function AccordionDemo() {
  return (
    <Accordion type="single" collapsible>
      <AccordionItem value="item-1">
        <AccordionTrigger>Section one</AccordionTrigger>
        <AccordionContent>Content for section one.</AccordionContent>
      </AccordionItem>
    </Accordion>
  )
}
```

## Props

### Accordion

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `type` | `"single"` \| `"multiple"` | — | Whether one or multiple items can be open |
| `defaultValue` | `string` \| `string[]` | — | Initially open item(s) (uncontrolled) |
| `value` | `string` \| `string[]` | — | Controlled open item(s) |
| `onValueChange` | `(value: string \| string[]) => void` | — | Callback when open state changes |
| `collapsible` | `boolean` | `false` | Allow closing the open item (type="single" only) |
| `className` | `string` | — | Additional Tailwind classes |

### AccordionItem

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | — | **Required.** Unique identifier for this item |
| `disabled` | `boolean` | `false` | Prevent the item from being opened |
| `className` | `string` | — | Additional Tailwind classes |

### AccordionTrigger

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional Tailwind classes |
| `children` | `ReactNode` | — | Trigger label content |

### AccordionContent

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional Tailwind classes |
| `children` | `ReactNode` | — | Expanded panel content |

## Notes

- Built on [`@radix-ui/react-accordion`](https://www.radix-ui.com/primitives/docs/components/accordion) — inherits full keyboard navigation and ARIA attributes.
- Trigger chevron (`▸` / `▾`) is rendered via CSS `content-['▸']` / `data-[state=open]:content-['▾']` — no icon dependency.
- Focus uses full foreground/background inversion (`focus-visible:bg-foreground focus-visible:text-background`) — no hover states.
- Disabled trigger renders in `text-foreground2` (Overlay 0) to match terminal dim-text convention.
- Content uses `ml-4 border-l border-border` for the left-indent TUI tree-structure aesthetic.
