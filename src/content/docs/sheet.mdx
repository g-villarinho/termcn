# Sheet

Terminal-style slide-out panel from any edge (top, right, bottom, left) with fade overlay, smooth animations, and bracket-style close button.

Built on Radix Dialog with slide transitions. Right side default, max-width 24rem. No hover/radius/shadow, depth via border and background levels.

## Installation

<InstallTabs pkg="@termcn/sheet" />

## Usage

```tsx
import { Sheet, SheetTrigger, SheetContent, SheetHeader, SheetTitle } from "@/components/ui/sheet"
import { Button } from "@/components/ui/button"

export default function SheetDemo() {
  return (
    <Sheet>
      <SheetTrigger asChild>
        <Button>Open Sheet</Button>
      </SheetTrigger>
      <SheetContent>
        <SheetHeader>
          <SheetTitle>Settings</SheetTitle>
        </SheetHeader>
        <p>Sheet content goes here.</p>
      </SheetContent>
    </Sheet>
  )
}
```

## Props

| Component | Prop | Type | Default | Description |
|-----------|------|------|---------|-------------|
| `Sheet` | — | Radix Root | — | Dialog root container |
| `SheetTrigger` | — | Radix Trigger | — | Button/element that opens sheet |
| `SheetContent` | `side` | `top` \| `right` \| `bottom` \| `left` | `right` | Which edge the sheet slides from |
| `SheetContent` | `className` | `string` | — | Additional Tailwind classes |
| `SheetContent` | ...rest | Radix Content props | — | All standard Radix Content props |
| `SheetHeader` | `className` | `string` | — | Wrapper for title/description |
| `SheetFooter` | `className` | `string` | — | Sticky footer (flex reverse) |
| `SheetTitle` | `className` | `string` | — | Renders with `▍` prefix |
| `SheetDescription` | `className` | `string` | — | Secondary text (muted foreground) |
| `SheetClose` | — | Radix Close | — | Manual close button |

## Notes

- Built on **Radix Dialog** — same accessibility properties as Dialog but with slide animations
- **Animations**: Fade overlay (150ms ease-out) + slide-in/out from selected edge (150ms ease-out)
- **Close button**: Bracket-style `[x]` in top-right corner, auto-rendered in `SheetContent`
- **Focus management**: Dialog handles focus trap and restore automatically
- **Keyboard**: <kbd>Esc</kbd> closes sheet; focus returns to trigger
- **Overlay**: Semi-transparent dark overlay (`bg-background/80`) dismisses sheet on click (unless `interaction-outside` disabled)
