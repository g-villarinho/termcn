# Alert Dialog

Terminal-style confirmation dialog built on Radix Alert Dialog. Unlike [Dialog](/docs/dialog), it interrupts the user and demands an explicit choice: there is no `[x]` close button and clicking outside does **not** dismiss it.

Dedicated `AlertDialogAction` (primary button) and `AlertDialogCancel` (ghost button) replace the generic close control. Uses `role="alertdialog"` and a 150ms opacity fade.

## Usage

```tsx
import {
  AlertDialog,
  AlertDialogTrigger,
  AlertDialogContent,
  AlertDialogHeader,
  AlertDialogFooter,
  AlertDialogTitle,
  AlertDialogDescription,
  AlertDialogAction,
  AlertDialogCancel,
} from "@/components/ui/alert-dialog"

export default function AlertDialogDemo() {
  return (
    <AlertDialog>
      <AlertDialogTrigger asChild>
        <Button>Delete</Button>
      </AlertDialogTrigger>
      <AlertDialogContent>
        <AlertDialogHeader>
          <AlertDialogTitle>Are you sure?</AlertDialogTitle>
          <AlertDialogDescription>
            This action cannot be undone.
          </AlertDialogDescription>
        </AlertDialogHeader>
        <AlertDialogFooter>
          <AlertDialogCancel>Cancel</AlertDialogCancel>
          <AlertDialogAction>Continue</AlertDialogAction>
        </AlertDialogFooter>
      </AlertDialogContent>
    </AlertDialog>
  )
}
```

## Props

| Sub-component | Purpose | Key props |
|------|---------|-----------|
| `AlertDialog` | Root state provider | `open`, `defaultOpen`, `onOpenChange` |
| `AlertDialogTrigger` | Element that opens the dialog | `asChild` |
| `AlertDialogContent` | Centered panel; `role="alertdialog"`, outside-click prevented | `className` |
| `AlertDialogOverlay` | Backdrop layer (auto-rendered by content) | `className` |
| `AlertDialogHeader` | Vertical title/description group | `className` |
| `AlertDialogTitle` | Accessible title | `className` |
| `AlertDialogDescription` | Muted description text | `className` |
| `AlertDialogFooter` | Action row (right-aligned on `sm`+) | `className` |
| `AlertDialogAction` | Confirm button (primary `buttonVariants`); closes on click | `className`, `onClick` |
| `AlertDialogCancel` | Dismiss button (ghost `buttonVariants`); closes on click | `className`, `onClick` |

All sub-components forward their standard [Radix Alert Dialog](https://www.radix-ui.com/primitives/docs/components/alert-dialog) props plus `className`.

## Notes

- Built on `@radix-ui/react-dialog` with alert semantics. `AlertDialogContent` sets `role="alertdialog"` and calls `onPointerDownOutside={(e) => e.preventDefault()}`, so clicking the backdrop will not close it — the user must choose Action or Cancel.
- There is no `[x]` close button (the key difference from [Dialog](/docs/dialog)). `AlertDialogAction` and `AlertDialogCancel` both wrap Radix `Close` and inherit `buttonVariants` (`primary` and `ghost` respectively).
- Animation is a single 150ms opacity fade — no scale, slide, or spring.
- Accessibility: focus is trapped while open, focus moves to the Cancel button by default, `Esc` closes, and title/description are linked via `aria-labelledby` / `aria-describedby`.
