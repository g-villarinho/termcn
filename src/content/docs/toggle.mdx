# Toggle

Terminal-style pressable button built on Radix Toggle. Two-state (on/off) with variant-driven pressed appearance. No hover, no radius, no shadow — interaction is communicated via focus and selection only.

## Installation

<InstallTabs pkg="@termcn/toggle" />

## Usage

```tsx
import { Toggle } from "@/components/ui/toggle"

export default function ToggleDemo() {
  return <Toggle>bold</Toggle>
}
```

### Controlled

```tsx
const [pressed, setPressed] = React.useState(false)

<Toggle pressed={pressed} onPressedChange={setPressed}>
  {pressed ? "on" : "off"}
</Toggle>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `default` \| `outline` | `default` | Visual style; `default` fills primary on press, `outline` inverts foreground |
| `size` | `default` \| `sm` \| `lg` | `default` | Toggle height and padding |
| `pressed` | `boolean` | — | Controlled pressed state |
| `defaultPressed` | `boolean` | `false` | Initial pressed state (uncontrolled) |
| `onPressedChange` | `(pressed: boolean) => void` | — | Callback when pressed state changes |
| `disabled` | `boolean` | `false` | Disable the toggle |
| `className` | `string` | — | Additional Tailwind classes |
| ...rest | `ComponentProps<typeof TogglePrimitive.Root>` | — | All Radix Toggle Root props |
