# Aspect Ratio

Terminal-style aspect ratio container. Radix-based wrapper that enforces a fixed width-to-height ratio. Renders a bordered box with background level 1, content stretched to fill.

Useful for media placeholders, image frames, and any layout that must maintain proportions regardless of container width.

## Installation

<InstallTabs pkg="@termcn/aspect-ratio" />

## Usage

```tsx
import { AspectRatio } from "@/components/ui/aspect-ratio"

export default function AspectRatioDemo() {
  return (
    <AspectRatio ratio={16 / 9}>
      <img src="/image.png" alt="Demo" className="size-full object-cover" />
    </AspectRatio>
  )
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `ratio` | `number` | `1` | Width-to-height ratio (e.g. `16/9`, `4/3`, `1`) |
| `className` | `string` | — | Additional Tailwind classes |
| `children` | `ReactNode` | — | Content to render inside the container |
| ...rest | `ComponentProps<AspectRatio.Root>` | — | All Radix AspectRatio root props |

## Notes

- The container applies `overflow-hidden`, `border border-border`, and `bg-background1` — consistent with the terminal depth system.
- Content inside fills the box via `size-full`. Use `object-cover` on images for cropped fills.
- The `ratio` prop accepts any number: `16/9`, `4/3`, `2.35` (cinemascope), `1` (square).
