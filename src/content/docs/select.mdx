# Select

Terminal-style menu-picker select (tmux choose-tree / ranger style). Opens a floating popover with a Command list — no search input. Navigate with arrow keys; selected item shows a ✓ indicator with Vim-style background inversion.

Built on Popover + Command + Button.

## Installation

<InstallTabs pkg="@termcn/select" />

## Usage

```tsx
import { Select } from "@/components/ui/select"
import type { SelectOption } from "@/components/ui/select"

const options: SelectOption[] = [
  { value: "neovim", label: "Neovim" },
  { value: "vim", label: "Vim" },
  { value: "emacs", label: "Emacs" },
]

export default function SelectDemo() {
  const [value, setValue] = React.useState("")

  return (
    <Select
      options={options}
      value={value}
      onValueChange={setValue}
    />
  )
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `options` | `SelectOption[]` | — | Array of selectable items |
| `value` | `string` | — | Controlled selected value |
| `onValueChange` | `(value: string) => void` | — | Called when selection changes |
| `placeholder` | `string` | `"select..."` | Text shown when no value selected |
| `emptyText` | `string` | `"-- empty --"` | Text shown when options array is empty |
| `disabled` | `boolean` | `false` | Disable the entire select |
| `className` | `string` | — | Additional classes on the trigger button |

### SelectOption type

```ts
interface SelectOption {
  value: string
  label: string
  disabled?: boolean
}
```

## Notes

- Composes **Popover** (floating container) + **Command** (keyboard list) + **Button** (trigger).
- No search input — use [Combobox](/docs/combobox) when filter-as-you-type is needed.
- Arrow-key navigation and selection via `Enter` are handled by cmdk's `Command` primitive.
- Selected item is highlighted with a `✓` indicator; active item uses Vim-style foreground/background inversion.
