# Navigation Menu

Terminal-style horizontal navigation menu built on [Radix NavigationMenu](https://www.radix-ui.com/primitives/docs/components/navigation-menu). Trigger items show a `▾` chevron and invert on open/focus. Dropdown panels fade in at 150ms. Links inside panels use focus-visible inversion. An optional indicator and animated viewport are included.

## Installation

<InstallTabs pkg="@termcn/navigation-menu" />

## Usage

```tsx
import {
  NavigationMenu,
  NavigationMenuList,
  NavigationMenuItem,
  NavigationMenuContent,
  NavigationMenuTrigger,
  NavigationMenuLink,
} from "@/components/ui/navigation-menu"

export default function NavigationMenuDemo() {
  return (
    <NavigationMenu>
      <NavigationMenuList>
        <NavigationMenuItem>
          <NavigationMenuTrigger>Products</NavigationMenuTrigger>
          <NavigationMenuContent>
            <NavigationMenuLink href="/products/one">Product One</NavigationMenuLink>
            <NavigationMenuLink href="/products/two">Product Two</NavigationMenuLink>
          </NavigationMenuContent>
        </NavigationMenuItem>
        <NavigationMenuItem>
          <NavigationMenuLink href="/docs">Docs</NavigationMenuLink>
        </NavigationMenuItem>
      </NavigationMenuList>
    </NavigationMenu>
  )
}
```

### Sub-menus

Use `NavigationMenuSub` to build a nested trigger/content pair inside a dropdown panel.

```tsx
<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuSub>
        <NavigationMenuTrigger>More</NavigationMenuTrigger>
        <NavigationMenuContent>
          <NavigationMenuLink href="#">Option A</NavigationMenuLink>
          <NavigationMenuLink href="#">Option B</NavigationMenuLink>
        </NavigationMenuContent>
      </NavigationMenuSub>
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>
```

## Props

| Sub-component | Props | Description |
|---------------|-------|-------------|
| `NavigationMenu` | `viewport`, `className`, `...RadixRoot` | Root; renders `NavigationMenuViewport` unless `viewport={false}` |
| `NavigationMenuList` | `className`, `...RadixList` | Horizontal bar with bottom border |
| `NavigationMenuItem` | `...RadixItem` | Wrapper for a single menu item |
| `NavigationMenuTrigger` | `className`, `...RadixTrigger` | Button with `▾` chevron; inverts on open and focus |
| `NavigationMenuContent` | `className`, `...RadixContent` | Dropdown panel; fades in/out at 150ms |
| `NavigationMenuLink` | `active`, `onSelect`, `className`, `...RadixLink` | Link inside a panel; inverts on `data-[active]` and `focus-visible:` |
| `NavigationMenuIndicator` | `className`, `...RadixIndicator` | Small `--primary` dot below the active trigger |
| `NavigationMenuViewport` | `className`, `...RadixViewport` | Animated container that wraps all open `Content` panels |
| `NavigationMenuSub` | `className`, `...RadixSub` | Nested sub-menu root |

### NavigationMenu props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `viewport` | `boolean` | `true` | Render the animated `NavigationMenuViewport`; set `false` for inline dropdowns |
| `className` | `string` | — | Additional Tailwind classes |

### NavigationMenuLink props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `active` | `boolean` | — | Marks link as current; applies foreground inversion via `data-[active]` |
| `onSelect` | `(event: Event) => void` | — | Fired when the link is activated |

## Notes

- Built on [Radix NavigationMenu](https://www.radix-ui.com/primitives/docs/components/navigation-menu) — keyboard navigation (arrow keys, `Escape`, `Tab`) is handled by the primitive.
- Trigger inversion is driven by `data-[state=open]` — no hover Tailwind variant is used.
- Content animations use the `termcn-fade` / `termcn-fade-out` keyframes (defined in `src/index.css`) at 150ms `ease-out`.
- `NavigationMenuViewport` is automatically rendered inside `NavigationMenu` when `viewport={true}` (default). Pass `viewport={false}` to skip it and let content position inline.
- `NavigationMenuList` has a bottom border (`border-b border-border`) that aligns visually with `TabsList` for consistent horizontal nav bars.
