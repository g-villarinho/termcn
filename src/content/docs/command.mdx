# Command

Terminal-style command palette built on [cmdk](https://cmdk.paco.me). Features an fzf-style `> ` prompt in the input, Vim visual-mode selection inversion on items, keyboard navigation, groups with headings, separators, and right-aligned shortcuts.

## Installation

<InstallTabs pkg="@termcn/command" />

## Usage

```tsx
import {
  Command,
  CommandInput,
  CommandList,
  CommandEmpty,
  CommandGroup,
  CommandItem,
  CommandShortcut,
  CommandSeparator,
} from "@/components/ui/command"

export default function CommandDemo() {
  return (
    <Command>
      <CommandInput placeholder="Type a command..." />
      <CommandList>
        <CommandEmpty>No results found.</CommandEmpty>
        <CommandGroup heading="Actions">
          <CommandItem>New file</CommandItem>
          <CommandItem>Open file</CommandItem>
        </CommandGroup>
      </CommandList>
    </Command>
  )
}
```

### With disabled items

Set `disabled` on `CommandItem` to prevent selection. Disabled items render in dim foreground and are skipped by keyboard navigation.

### With onSelect

Pass `onSelect` to `CommandItem` to handle selection. Triggered on click or `Enter`.

```tsx
<CommandItem onSelect={() => console.log("selected")}>
  Run command
</CommandItem>
```

## Props

| Sub-component | Props | Description |
|---------------|-------|-------------|
| `Command` | `className`, `...cmdk.CommandProps` | Root wrapper (cmdk `Command`) |
| `CommandInput` | `placeholder`, `className`, `...cmdk.InputProps` | Search input with fzf-style `> ` prompt |
| `CommandList` | `className`, `...cmdk.ListProps` | Scrollable results container (`max-h-72`) |
| `CommandEmpty` | `className`, `...cmdk.EmptyProps` | Shown when search returns no matches |
| `CommandGroup` | `heading`, `className`, `...cmdk.GroupProps` | Labelled item group; heading styled as dim uppercase |
| `CommandItem` | `value`, `disabled`, `onSelect`, `className`, `...cmdk.ItemProps` | Selectable item with foreground inversion on selection |
| `CommandShortcut` | `className`, `...ComponentProps<"span">` | Right-aligned keyboard shortcut hint |
| `CommandSeparator` | `className`, `...cmdk.SeparatorProps` | 1px horizontal divider (`bg-border`) |

### CommandItem props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | — | Used for fuzzy filtering; defaults to text content |
| `disabled` | `boolean` | `false` | Prevents selection; renders in `--foreground2` |
| `onSelect` | `(value: string) => void` | — | Called on click or `Enter` |

## Notes

- Built on [cmdk](https://cmdk.paco.me) — fuzzy filtering is handled automatically based on `value` or text content.
- Selection inversion (`bg-foreground text-background`) is driven by `data-[selected=true]` set by cmdk during keyboard navigation and mouse hover — no hover Tailwind variant is used.
- Compose `Command` inside a `Dialog` or `Popover` to build a full command palette overlay (see the `combobox` docs).
- `CommandShortcut` uses `ml-auto` to push the key hint to the right edge of the item.
