# termcn

Terminal-inspired components built on shadcn/ui. Catppuccin Mocha theme, JetBrains Mono, sharp edges. Open Source.

## Documentation

Visit https://termcn.dev/docs to view the documentation.

## Installation

```bash
npx shadcn@latest add https://termcn.dev/r/styles/termcn/button.json
```
