# Calendar

Display and select dates with a terminal-inspired calendar component featuring grid-based layout and ANSI color accents.

## Overview

The Calendar component is a date picker interface built on top of `react-day-picker`. It features a distinctive terminal aesthetic with monospace typography, grid-based borders reminiscent of classic TUI applications, and ANSI color accents for visual hierarchy. The component supports single date selection, date ranges, and multiple date selection modes while maintaining full accessibility.

## Features

- **Terminal Grid Layout**: Border-based cell structure that evokes classic text-based interfaces
- **ANSI Color Accents**: Cyan weekday headers, yellow today indicator, and blue selection states
- **Multiple Selection Modes**: Single date, date ranges, and multiple date selection
- **Monospace Typography**: JetBrains Mono font for authentic terminal appearance
- **Navigation Controls**: Chevron-based month navigation with hover states
- **Outside Days Display**: Optional visibility of days from adjacent months
- **Fully Accessible**: Keyboard navigation, ARIA labels, and screen reader support
- **Highly Customizable**: Extensible classNames and custom components support

## Common Use Cases

### Date Input Field

Combine with Popover for a date picker input:

```tsx
import { useState } from "react";
import { Calendar } from "@/components/ui/calendar";
import { Popover, PopoverContent, PopoverTrigger } from "@/components/ui/popover";
import { Button } from "@/components/ui/button";
import { CalendarIcon } from "lucide-react";
import { format } from "date-fns";

export default function DatePicker() {
  const [date, setDate] = useState<Date>();

  return (
    <Popover>
      <PopoverTrigger asChild>
        <Button variant="outline">
          <CalendarIcon className="mr-2 h-4 w-4" />
          {date ? format(date, "PPP") : "Pick a date"}
        </Button>
      </PopoverTrigger>
      <PopoverContent className="w-auto p-0">
        <Calendar
          mode="single"
          selected={date}
          onSelect={setDate}
        />
      </PopoverContent>
    </Popover>
  );
}
```

### Booking Calendar

Date range selection for reservations:

```tsx
import { useState } from "react";
import { Calendar } from "@/components/ui/calendar";
import { DateRange } from "react-day-picker";
import { addDays } from "date-fns";

export default function BookingCalendar() {
  const [range, setRange] = useState<DateRange | undefined>({
    from: new Date(),
    to: addDays(new Date(), 7),
  });

  // Disable past dates
  const disabledDays = { before: new Date() };

  return (
    <Calendar
      mode="range"
      selected={range}
      onSelect={setRange}
      disabled={disabledDays}
      numberOfMonths={2}
    />
  );
}
```

## API Reference

### Calendar Props

The Calendar component accepts all `DayPickerProps` from `react-day-picker` plus these commonly used props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `mode` | `"single" \| "range" \| "multiple"` | `undefined` | Selection mode for the calendar |
| `selected` | `Date \| DateRange \| Date[]` | `undefined` | Currently selected date(s) |
| `onSelect` | `(date) => void` | `undefined` | Callback when date selection changes |
| `showOutsideDays` | `boolean` | `true` | Show days from adjacent months |
| `disabled` | `Matcher \| Matcher[]` | `undefined` | Dates to disable |
| `fromDate` | `Date` | `undefined` | Earliest selectable date |
| `toDate` | `Date` | `undefined` | Latest selectable date |
| `defaultMonth` | `Date` | `undefined` | Initial month to display |
| `numberOfMonths` | `number` | `1` | Number of months to display |
| `className` | `string` | `undefined` | Additional CSS classes for root |
| `classNames` | `object` | `undefined` | Custom classes for internal elements |

## Best Practices

### When to Use Calendar

✅ **Good Use Cases:**
- Date selection in forms
- Booking and reservation systems
- Event scheduling interfaces
- Date range filtering
- Birthday or date of birth pickers

❌ **Avoid Using Calendar For:**
- Time-only selection (use time picker instead)
- Simple date display (use formatted text)
- Date arithmetic display (show computed dates as text)
- Very constrained spaces (consider alternative input)

### Design Guidelines

1. **Provide context**: Include labels indicating what the date is for
2. **Show selected state clearly**: The blue highlight should be visible
3. **Disable invalid dates**: Prevent selection of past dates for bookings
4. **Consider mobile**: Touch targets should be adequate (minimum 44x44px)
5. **Limit choices**: Constrain date ranges when appropriate
6. **Show today clearly**: Yellow indicator helps orientation

## Design Details

### Grid-Based Terminal Aesthetic

The Calendar uses a grid layout with visible borders to evoke classic TUI (Text User Interface) applications:

**Grid Structure:**
- Each day cell has right and bottom borders
- Last column cells have right border removed
- Weekday headers have distinct background
- Month navigation positioned absolutely for clean layout

**Color Coding:**
- Cyan (`--ansi-cyan`): Weekday abbreviations
- Yellow (`--ansi-yellow`): Today's date
- Blue (`--ansi-blue`): Selected dates and range endpoints
- Muted (`--background2`): Range middle dates

### Monospace Alignment

The `font-mono` class ensures perfect character alignment in the grid, creating the authentic terminal appearance where all characters occupy equal horizontal space.

## Troubleshooting

### Calendar not displaying correctly

Ensure react-day-picker is installed:

```bash
pnpm add react-day-picker
```

### Dates not selecting

Verify the `mode` prop matches your selection handler:

```tsx
{/* Correct */}
<Calendar mode="single" selected={date} onSelect={setDate} />

{/* Incorrect - mode doesn't match handler */}
<Calendar mode="range" selected={date} onSelect={setDate} />
```

### Styling not applying

Check that Tailwind CSS is configured to include the calendar component:

```js
// tailwind.config.js
module.exports = {
  content: [
    "./src/**/*.{js,ts,jsx,tsx}",
    // Include registry if using source components
    "./registry/**/*.{js,ts,jsx,tsx}",
  ],
};
```

### Month navigation not working

Ensure the Chevron component is properly imported:

```tsx
import { ChevronLeftIcon, ChevronRightIcon } from "lucide-react";
```
