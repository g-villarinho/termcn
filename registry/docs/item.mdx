# Item

Versatile list item component with composable structure for building navigation menus, file lists, settings panels, and data displays.

## Overview

The Item component is a flexible, composable building block designed for creating structured lists and navigation interfaces. Built with terminal aesthetics in mind, it features monospace typography, clean borders, and thoughtful hover states that feel native to command-line interfaces.

## Installation

```bash
npx termcn add item
```

This will install the Item component and its dependencies into your project.

## Dependencies

- `@radix-ui/react-slot` - For polymorphic component rendering
- `class-variance-authority` - For type-safe variant management
- `@/lib/utils` - For className merging utilities

## Structure

The Item component is composed of several sub-components that work together:

| Component | Description |
|-----------|-------------|
| `Item` | The main container for a single list item |
| `ItemGroup` | Wrapper that groups items with proper list semantics |
| `ItemMedia` | Container for icons, avatars, or other media |
| `ItemContent` | Main content area with title and description |
| `ItemTitle` | Primary text/heading for the item |
| `ItemDescription` | Secondary descriptive text |
| `ItemActions` | Right-aligned container for actions, badges, or shortcuts |
| `ItemSeparator` | Visual divider between items |

- `default`: Transparent background - clean and minimal
- `muted`: Subtle background color - useful for zebra striping or sections
- `active`: Highlighted with blue accent text - indicates current selection

```tsx
{/* Custom width */}

<Item className="bg-ansi-blue/10 border-l-2 border-ansi-blue" />

```

### Theme Integration

The Item component uses CSS variables from the TermCN theme system:

- `--background1` / `--background2` - Layer backgrounds
- `--border` - Border color
- `--foreground` / `--foreground2` - Text colors
- `--ansi-blue` - Active state accent

### Styling Icons in ItemMedia

ItemMedia automatically styles nested SVG icons:

```tsx
{/* Default icon styling */}
<ItemMedia>
  <Icon /> {/* Gets size-4 and text-foreground2 */}
</ItemMedia>

{/* Override with custom classes */}
<ItemMedia>
  <Icon className="size-5 text-ansi-cyan" />
</ItemMedia>
```

## Best Practices

### When to Use Item

**Good Use Cases:**
- Navigation menus and sidebars
- File explorers and tree views
- Command palettes and search results
- Settings panels and preference lists
- Notification and activity feeds
- Data lists with actions

**Avoid Using Item For:**
- Grid layouts (use CSS Grid or Card)
- Table data (use Table component)
- Single standalone elements
- Complex multi-column layouts

### Composition Guidelines

```tsx
{/* Good - clear structure */}
<Item>
  <ItemMedia><Icon /></ItemMedia>
  <ItemContent>
    <ItemTitle>Title</ItemTitle>
    <ItemDescription>Description</ItemDescription>
  </ItemContent>
  <ItemActions><Badge>Label</Badge></ItemActions>
</Item>

{/* Avoid - missing semantic structure */}
<Item>
  <Icon />
  <span>Title</span>
  <span>Description</span>
</Item>
```

### Interactive Items

```tsx
{/* Good - clear interaction pattern */}
<Item interactive asChild>
  <Link to="/page">
    <ItemContent><ItemTitle>Navigate</ItemTitle></ItemContent>
  </Link>
</Item>

{/* Good - button with click handler */}
<Item interactive onClick={handleClick}>
  <ItemContent><ItemTitle>Action</ItemTitle></ItemContent>
</Item>
```
