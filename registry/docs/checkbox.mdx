# Checkbox

Toggle boolean states with terminal-inspired bracket-style checkboxes featuring authentic ASCII aesthetics.

## Overview

The Checkbox component is a fundamental form element designed to capture binary choices from users. Built with a distinctive terminal aesthetic, it features a unique bracket-style design `[X]` that evokes the feel of classic command-line interfaces, configuration files, and retro computing forms. The component leverages Radix UI primitives for robust accessibility while maintaining the authentic monospace typography of terminal applications.

## Features

- **ASCII Bracket Design**: Distinctive `[X]` / `[ ]` pattern inspired by terminal checkboxes
- **Terminal Typography**: JetBrains Mono font for authentic command-line aesthetics
- **Radix UI Foundation**: Built on @radix-ui/react-checkbox for robust accessibility
- **Smooth State Transitions**: Visual feedback through opacity and font-weight changes
- **Keyboard Accessible**: Full keyboard navigation with focus-visible states
- **Customizable Sizing**: Flexible width and height using character-based dimensions
- **Disabled State Support**: Clear visual indication for non-interactive states
- **TypeScript Support**: Fully typed with comprehensive prop definitions

### Form with Validation

```tsx
import { useState } from "react";
import { Checkbox } from "@/components/ui/checkbox";
import { Button } from "@/components/ui/button";

export default function FormWithCheckbox() {
  const [agreed, setAgreed] = useState(false);
  const [error, setError] = useState(false);

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (!agreed) {
      setError(true);
      return;
    }
    // Submit form
  };

  return (
    <form onSubmit={handleSubmit} className="flex flex-col gap-4">
      <div className="flex items-center gap-2">
        <Checkbox
          id="terms"
          checked={agreed}
          onCheckedChange={(checked) => {
            setAgreed(checked === true);
            setError(false);
          }}
          className={error ? "text-destructive" : ""}
        />
        <label htmlFor="terms" className={error ? "text-destructive" : ""}>
          I accept the terms
        </label>
      </div>
      {error && (
        <p className="text-sm text-destructive">
          You must accept the terms to continue
        </p>
      )}
      <Button type="submit">Submit</Button>
    </form>
  );
}
```

## API Reference

### Checkbox Props

The Checkbox component extends `React.ComponentProps<typeof CheckboxPrimitive.Root>` and accepts the following props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `checked` | `boolean \| "indeterminate"` | `undefined` | The controlled checked state |
| `defaultChecked` | `boolean` | `false` | The default checked state (uncontrolled) |
| `onCheckedChange` | `(checked: boolean \| "indeterminate") => void` | `undefined` | Callback when checked state changes |
| `disabled` | `boolean` | `false` | Disable the checkbox |
| `required` | `boolean` | `false` | Mark as required for form validation |
| `name` | `string` | `undefined` | Name attribute for form submission |
| `value` | `string` | `"on"` | Value attribute for form submission |
| `className` | `string` | `undefined` | Additional CSS classes to apply |
| ...rest | `CheckboxPrimitive.Root` props | - | All Radix UI Checkbox props are supported |

### Type Definitions

```typescript
import * as CheckboxPrimitive from "@radix-ui/react-checkbox";

export interface CheckboxProps
  extends React.ComponentProps<typeof CheckboxPrimitive.Root> {}
```

## Best Practices

### When to Use Checkbox

✅ **Good Use Cases:**
- Binary yes/no choices (agree, subscribe, enable)
- Multi-select options from a list
- Todo items and task lists
- Settings and preferences toggles
- Form consent and agreements
- Selecting items for bulk actions

❌ **Avoid Using Checkbox For:**
- Single exclusive choices (use Radio instead)
- On/off toggles with immediate effect (use Switch instead)
- Navigation or triggering actions (use Button instead)
- Selecting a single option from many (use Select instead)

### Design Guidelines

1. **Always provide labels**: Every checkbox should have a visible label or accessible name
2. **Use clear, positive language**: "Enable notifications" instead of "Don't disable notifications"
3. **Group related checkboxes**: Use fieldset and legend for related options
4. **Consider default states**: Pre-check options that are commonly selected
5. **Align consistently**: Keep checkboxes aligned vertically for scanability
6. **Use proper spacing**: Provide adequate touch targets and visual separation

## Design Details

### ASCII Bracket Pattern

The checkbox uses a distinctive terminal-style bracket pattern:

```
Unchecked: [ ]
Checked:   [X]
```

This design is achieved through the following structure:

```tsx
<span>[</span>
<CheckboxPrimitive.Indicator>
  <span>X</span>
</CheckboxPrimitive.Indicator>
<span className="group-data-[state=checked]:hidden"> </span>
<span>]</span>
```

### Typography

The component uses monospace font (`font-mono`) for authentic terminal aesthetics:

```tsx
className="font-mono text-sm leading-normal"
```

### Character-Based Sizing

Width is based on character units for proper monospace alignment:

```tsx
className="w-[3ch] h-lh min-w-0"
```

- `w-[3ch]`: Width of 3 characters (bracket + content + bracket)
- `h-lh`: Height equals line-height for vertical alignment

### State Styling

**Default State:**
- Text color: 60% opacity (`text-foreground/60`)

**Focus State:**
- Full opacity text (`text-foreground`)
- Bold font weight (`font-bold`)

**Disabled State:**
- 40% opacity (`text-foreground/40`)
- No pointer events

### Indeterminate State

```tsx
import { useState } from "react";
import { Checkbox } from "@/components/ui/checkbox";

export default function IndeterminateExample() {
  const [items, setItems] = useState([
    { id: 1, label: "Item 1", checked: true },
    { id: 2, label: "Item 2", checked: false },
    { id: 3, label: "Item 3", checked: true },
  ]);

  const allChecked = items.every((item) => item.checked);
  const someChecked = items.some((item) => item.checked);
  const parentChecked = allChecked ? true : someChecked ? "indeterminate" : false;

  const handleParentChange = (checked: boolean | "indeterminate") => {
    const newChecked = checked === true;
    setItems(items.map((item) => ({ ...item, checked: newChecked })));
  };

  return (
    <div className="flex flex-col gap-2">
      <div className="flex items-center gap-2">
        <Checkbox
          checked={parentChecked}
          onCheckedChange={handleParentChange}
        />
        <label className="font-bold">Select all</label>
      </div>
      {items.map((item) => (
        <div key={item.id} className="flex items-center gap-2 pl-4">
          <Checkbox
            checked={item.checked}
            onCheckedChange={(checked) =>
              setItems(items.map((i) =>
                i.id === item.id ? { ...i, checked: checked === true } : i
              ))
            }
          />
          <label>{item.label}</label>
        </div>
      ))}
    </div>
  );
}
```

## Troubleshooting

### Checkbox not toggling

Ensure you're not mixing controlled and uncontrolled patterns:

```tsx
{/* Wrong - don't set both checked and defaultChecked */}
<Checkbox checked={checked} defaultChecked />

{/* Correct - controlled */}
<Checkbox checked={checked} onCheckedChange={setChecked} />

{/* Correct - uncontrolled */}
<Checkbox defaultChecked />
```

### Label not clicking checkbox

Make sure the `htmlFor` attribute matches the checkbox `id`:

```tsx
{/* Wrong - mismatched IDs */}
<Checkbox id="checkbox1" />
<label htmlFor="checkbox2">Label</label>

{/* Correct */}
<Checkbox id="terms" />
<label htmlFor="terms">Accept terms</label>
```

### Checkbox indicator not showing

Verify the component is properly imported and rendered:

```tsx
import { Checkbox } from "@/components/ui/checkbox";

// Make sure you're using the component, not just CheckboxPrimitive
<Checkbox defaultChecked />
```

### Custom styling not applying

Check that your className is being merged correctly:

```tsx
{/* Use cn() if extending the component */}
<Checkbox className="text-success" />
```

## Migration Guide

### From shadcn/ui Checkbox

The TermCN Checkbox has a unique bracket-style design:

```diff
  import { Checkbox } from "@/components/ui/checkbox";

  // Basic usage remains the same
  <Checkbox />
  <Checkbox defaultChecked />
  <Checkbox disabled />

  // Controlled state works identically
  <Checkbox checked={checked} onCheckedChange={setChecked} />

- // Visual difference: shadcn uses a square with checkmark

  // All Radix UI props are still supported

    id="terms"
    required
    name="terms"
    value="accepted"
  />
```

```diff
- <input type="checkbox" id="terms" checked={checked} onChange={(e) => setChecked(e.target.checked)} />

```
