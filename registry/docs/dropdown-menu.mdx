# DropdownMenu

Display a menu of actions and options with terminal-inspired dropdown components featuring keyboard navigation and nested submenus.

## Overview

The DropdownMenu component is a versatile UI element for displaying a list of actions, options, or navigation items in a floating panel. Built with Radix UI primitives and styled with a terminal aesthetic, it features bold 2px borders, monospace typography, and smooth animations that evoke command-line interfaces and retro computing menus. The component supports checkbox items, radio groups, nested submenus, keyboard shortcuts display, and full accessibility out of the box.

## Features

- **Terminal Aesthetic**: Bold 2px borders, monospace font, and dark theme integration
- **Multiple Item Types**: Standard items, checkbox items, radio items, labels, and separators
- **Nested Submenus**: Full support for multi-level menu hierarchies with animated transitions
- **Keyboard Navigation**: Complete arrow key navigation, type-ahead search, and shortcut display
- **Variant Support**: Default and destructive variants for different action types
- **Fully Accessible**: ARIA-compliant with proper roles, states, and keyboard interactions
- **Animation System**: Smooth open/close animations with zoom and slide effects
- **TypeScript Support**: Fully typed with comprehensive prop definitions

## Installation

```bash
npx termcn add dropdown-menu
```

This will install the DropdownMenu component and its dependencies into your project.

## Dependencies

- `@radix-ui/react-dropdown-menu` - Headless dropdown menu primitives
- `lucide-react` - Icon library for check, chevron, and circle icons
- `@/lib/utils` - For className merging utilities

## API Reference

### DropdownMenu

The root component that wraps all dropdown menu elements.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | `undefined` | Controlled open state |
| `defaultOpen` | `boolean` | `false` | Default open state (uncontrolled) |
| `onOpenChange` | `(open: boolean) => void` | `undefined` | Callback when open state changes |
| `modal` | `boolean` | `true` | Whether the menu is modal |
| `dir` | `"ltr" \| "rtl"` | `"ltr"` | Reading direction |

### DropdownMenuTrigger

The button that toggles the dropdown menu.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `asChild` | `boolean` | `false` | Render as child element using Slot |

### DropdownMenuContent

The container for the dropdown menu items.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `sideOffset` | `number` | `4` | Distance from trigger in pixels |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | Preferred side to render |
| `align` | `"start" \| "center" \| "end"` | `"start"` | Alignment relative to trigger |
| `alignOffset` | `number` | `0` | Offset from alignment |
| `className` | `string` | `undefined` | Additional CSS classes |

### DropdownMenuItem

A single menu item.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "destructive"` | `"default"` | Visual style variant |
| `inset` | `boolean` | `false` | Add left padding for alignment |
| `disabled` | `boolean` | `false` | Disable the item |
| `onSelect` | `(event: Event) => void` | `undefined` | Callback when selected |
| `className` | `string` | `undefined` | Additional CSS classes |

### DropdownMenuCheckboxItem

A menu item with a checkbox.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `checked` | `boolean` | `false` | Checked state |
| `onCheckedChange` | `(checked: boolean) => void` | `undefined` | Callback when state changes |
| `disabled` | `boolean` | `false` | Disable the item |
| `className` | `string` | `undefined` | Additional CSS classes |

### DropdownMenuRadioGroup

A group of radio items where only one can be selected.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | `undefined` | Selected value |
| `onValueChange` | `(value: string) => void` | `undefined` | Callback when selection changes |

### DropdownMenuRadioItem

A radio item within a radio group.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | **required** | The value of the item |
| `disabled` | `boolean` | `false` | Disable the item |
| `className` | `string` | `undefined` | Additional CSS classes |

### DropdownMenuLabel

A label for a group of items.

| Prop | Type | Default | Description |
|------|------|---------|-------------|

## Best Practices

### When to Use DropdownMenu

✅ **Good Use Cases:**
- User profile menus with account actions
- Table row action menus (edit, delete, duplicate)
- Filter or sort options
- Context-sensitive actions
- Settings toggles and preferences
- Navigation with submenus

❌ **Avoid Using DropdownMenu For:**
- Primary navigation (use proper nav components)
- Single actions (use a button instead)
- Form inputs (use Select component)
- Content that needs to persist (use Popover)
- Critical actions without confirmation (use Dialog)

### Design Guidelines

1. **Keep menus concise**: Limit to 7±2 items per level to avoid overwhelming users
2. **Use logical grouping**: Separate related items with labels and separators
3. **Indicate shortcuts**: Always display keyboard shortcuts when available
4. **Destructive actions last**: Place dangerous actions at the bottom with a separator
5. **Use appropriate variants**: Apply destructive variant only for irreversible actions
6. **Consider mobile**: Menus work well on mobile but test touch interactions
7. **Avoid deep nesting**: Limit submenus to 2 levels maximum

### Performance Considerations

1. **Lazy content**: Menu content is rendered only when open
2. **Portal rendering**: Content renders in a portal to avoid z-index issues
3. **Animation optimization**: Uses CSS transforms for smooth 60fps animations
4. **Event delegation**: Radix handles events efficiently at the root level

## Troubleshooting

### Menu appears behind other elements

Ensure proper z-index stacking. The menu uses `z-50` by default:

```tsx
<DropdownMenuContent className="z-[100]">
  {/* Higher z-index if needed */}
</DropdownMenuContent>
```

### Menu closes immediately after opening

Check for click handlers on parent elements that might be calling `stopPropagation()`:

```tsx
{/* Avoid this pattern */}
<div onClick={(e) => e.stopPropagation()}>
  <DropdownMenu>...</DropdownMenu>
</div>
```

### Keyboard shortcuts not working

Ensure shortcuts are properly connected to your event handlers:

```tsx
useEffect(() => {
  const handleKeyDown = (e: KeyboardEvent) => {
    if (e.ctrlKey && e.key === "n") {
      e.preventDefault();
      handleNewFile();
    }
  };
  document.addEventListener("keydown", handleKeyDown);
  return () => document.removeEventListener("keydown", handleKeyDown);
}, []);
```

### Submenu not opening

Verify the submenu structure is correct:

```tsx
<DropdownMenuSub>
  <DropdownMenuSubTrigger>Submenu</DropdownMenuSubTrigger>
  <DropdownMenuSubContent>
    {/* Content must be inside SubContent */}
    <DropdownMenuItem>Item</DropdownMenuItem>
  </DropdownMenuSubContent>
</DropdownMenuSub>
```
