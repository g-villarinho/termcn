# Progress

Terminal-style progress bars with ASCII characters or visual bar mode.

## Installation

```bash
npx termcn add progress
```

## Usage

### Basic

<ComponentPreview>
  <Progress value={60} />
</ComponentPreview>

```tsx
import { Progress } from "@/components/ui/progress";

<Progress value={60} />
```

## API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | `0` | Progress value (0 to max) |
| `max` | `number` | `100` | Maximum value |
| `mode` | `"char" \| "bar"` | `"char"` | Display mode |
| `fillChar` | `"block" \| "hash" \| "arrow" \| "equals" \| "dot" \| "pipe" \| "shade" \| "line" \| string` | `"block"` | Fill character |
| `showPercent` | `boolean` | `false` | Show percentage |
| `showBrackets` | `boolean` | `true` | Show `< >` brackets |
| `charWidth` | `number` | `20` | Character width |
| `variant` | `"default" \| "success" \| "warning" \| "destructive" \| "muted"` | `"default"` | Color variant |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Size |
