# Textarea

Multi-line text input with terminal aesthetics for capturing longer content like comments, descriptions, and messages.

## Overview

The Textarea component is a multi-line text input designed for capturing longer form content such as comments, descriptions, messages, and code snippets. Built with a terminal-inspired aesthetic, it features a monospace font, minimal styling, and clean vertical resize functionality that evokes the feel of classic terminal text editors.

## Features

- **2 Visual Variants**: Default (minimal) and Bordered for different visual contexts
- **3 Size Options**: Small, Default, and Large for various content needs
- **Terminal Aesthetics**: Monospace font family for code-like appearance
- **Vertical Resizing**: Native resize handle for user-controlled height adjustment
- **Custom Selection**: Themed text selection with primary color highlighting
- **Fully Accessible**: Proper form integration and disabled states
- **TypeScript Support**: Fully typed with comprehensive prop definitions
- **Lightweight**: Minimal styling that extends native textarea behavior

## Installation

```bash
npx termcn add textarea
```

This will install the Textarea component and its dependencies into your project.

### Controlled Textarea

```tsx

import { Textarea } from "@/components/ui/textarea";

export default function ControlledExample() {
  const [value, setValue] = useState("");

  return (
    <div>
      <Textarea
        value={value}
        onChange={(e) => setValue(e.target.value)}
        placeholder="Controlled textarea..."
      />
      <p>Character count: {value.length}</p>
    </div>
  );
}
```

## API Reference

### Textarea Props

The Textarea component extends `React.ComponentProps<"textarea">` and accepts the following props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "bordered"` | `"default"` | The visual style variant |
| `textareaSize` | `"sm" \| "default" \| "lg"` | `"default"` | The size of the textarea |
| `className` | `string` | `undefined` | Additional CSS classes to apply |
| `placeholder` | `string` | `undefined` | Placeholder text when empty |
| `disabled` | `boolean` | `false` | Disable the textarea |
| `rows` | `number` | `undefined` | Number of visible text lines |
| `maxLength` | `number` | `undefined` | Maximum character limit |
| ...rest | `TextareaHTMLAttributes` | - | All standard textarea attributes are supported |

### Type Definitions

```typescript
import { VariantProps } from "class-variance-authority";

export interface TextareaProps
  extends React.ComponentProps<"textarea">,
    VariantProps<typeof textareaVariants> {}
```

### Theme Integration

The Textarea component uses CSS variables from the TermCN theme system:

- `--background` - Textarea background color
- `--foreground` - Text color
- `--muted-foreground` - Placeholder text color
- `--border` - Border color (bordered variant)
- `--primary` - Focus border color and text selection
- `--primary-foreground` - Selected text color

### Extending Variants

To add custom variants, modify the `textareaVariants` CVA definition:

```typescript
const textareaVariants = cva(
  [
    "w-full bg-background text-foreground placeholder:text-muted-foreground",
    "border-0 outline-none resize-vertical",
    "font-mono transition-colors",
    "selection:bg-primary selection:text-primary-foreground",
    "disabled:pointer-events-none disabled:cursor-not-allowed disabled:opacity-50",
  ],
  {
    variants: {
      variant: {
        // ... existing variants
        custom: "border-2 border-accent focus:border-accent-foreground",
      },
      textareaSize: {
        // ... existing sizes
      },
    },
  }
);
```

## Accessibility

### Form Labels

Always associate textareas with labels for screen reader support:

```tsx
{/* Using htmlFor */}
<label htmlFor="description">Description</label>
<Textarea id="description" />

{/* Using aria-label for icon-only contexts */}
<Textarea aria-label="Message content" placeholder="Type here..." />

{/* Using aria-labelledby for complex labels */}
<h3 id="feedback-title">Feedback</h3>
<Textarea aria-labelledby="feedback-title" />
```

### Keyboard Navigation

- **Tab**: Focus the textarea
- **Shift + Tab**: Move focus to previous element
- **Standard text editing**: All native keyboard shortcuts work (Ctrl+A, Ctrl+C, etc.)

### Screen Reader Support

```tsx
{/* Provide context with aria-describedby */}
<Textarea
  id="message"
  aria-describedby="message-hint"
  placeholder="Enter message..."
/>
<p id="message-hint" className="text-xs text-muted-foreground">
  Maximum 500 characters
</p>

{/* Required field indication */}
<Textarea
  required
  aria-required="true"
  placeholder="Required field"
/>

{/* Invalid state */}
<Textarea
  aria-invalid="true"
  aria-errormessage="error-msg"
/>
<p id="error-msg" className="text-destructive">
  This field is required
</p>
```

## Best Practices

### When to Use Textarea

✅ **Good Use Cases:**
- Comments and feedback forms
- Message composition (email, chat)
- Code or text snippet input
- Bio and description fields
- Notes and multi-paragraph content
- JSON or configuration input

❌ **Avoid Using Textarea For:**
- Single-line input (use Input instead)
- Password fields (use Input with type="password")
- Numeric input (use Input with type="number")
- Date/time selection (use dedicated date pickers)
- Rich text editing (use a rich text editor)

### Design Guidelines

1. **Set appropriate rows**: Match visible rows to expected content length
2. **Use placeholder wisely**: Provide helpful examples, not instructions
3. **Consider character limits**: Show limits when applicable
4. **Label clearly**: Always pair with visible or accessible labels
5. **Size appropriately**: Use size variants to match form hierarchy
6. **Allow resizing**: Don't disable resize unless necessary

## Design Details

### Typography

The Textarea uses monospace font (`font-mono`) to evoke terminal aesthetics and ensure consistent character width, making it ideal for code-like content.

### Sizing Implementation

Sizes use line-height units (`lh`) for minimum height, ensuring consistent vertical rhythm:

```typescript
textareaSize: {
  sm: "min-h-[2lh] px-0 py-0 text-xs",        // 2 lines, no padding, 12px text
  default: "min-h-[2lh] px-[1ch] py-1 text-sm", // 2 lines, 1ch padding, 14px text
  lg: "min-h-[4lh] px-[2ch] py-[1lh] text-base", // 4 lines, 2ch padding, 16px text
}
```

### Character-Based Padding

Horizontal padding uses character width units (`ch`) to align with the monospace aesthetic:
- Small: No horizontal padding
- Default: 1 character width padding
- Large: 2 character width padding

## Troubleshooting

### Textarea not resizing

Ensure resize is not disabled:

```tsx
{/* Default - resizable */}
<Textarea placeholder="Can resize vertically" />

{/* If resize was disabled, re-enable it */}
<Textarea className="resize-vertical" placeholder="Resizable" />
```

### Placeholder text not visible

Check that placeholder color has sufficient contrast:

```tsx
{/* Use the muted-foreground color from theme */}
<Textarea
  className="placeholder:text-muted-foreground"
  placeholder="Should be visible"
/>
```

### Theme colors not applying

Verify your CSS variables are properly defined:

```css
:root {
  --background: 240 10% 3.9%;
  --foreground: 0 0% 98%;
  --muted-foreground: 240 5% 64.9%;
  --primary: 262.1 83.3% 57.8%;
  --primary-foreground: 0 0% 98%;
  /* ... other variables */
}
```

### Text selection not themed

Ensure selection pseudo-element styles are supported:

```tsx
<Textarea
  className="selection:bg-primary selection:text-primary-foreground"
  placeholder="Select text to see themed selection"
/>
```
