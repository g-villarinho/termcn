# Kbd

Display keyboard shortcuts and key combinations with terminal-inspired styling.

## Overview

The Kbd component renders keyboard keys and shortcuts in a visually distinct manner, perfect for documentation, tooltips, and command palettes. Built with a terminal aesthetic, it features monospace typography, sharp corners, and subtle borders that evoke the look of physical keyboard keys in a CLI environment.

## Features

- **3 Visual Variants**: Default, Outline, and Ghost for different emphasis levels
- **2 Size Options**: Default and Small for flexible placement
- **Terminal Aesthetic**: Monospace font, sharp corners, and muted colors
- **Composition Pattern**: Support for asChild prop using Radix UI Slot
- **KbdGroup Component**: Easily combine multiple keys for shortcuts
- **Icon Support**: Seamless integration with SVG icons for modifier keys
- **Fully Accessible**: Semantic kbd element with proper styling
- **TypeScript Support**: Fully typed with comprehensive prop definitions

## Installation

```bash
npx termcn add kbd
```

This will install the Kbd component and its dependencies into your project.

## Dependencies

- `@radix-ui/react-slot` - For composition pattern support
- `class-variance-authority` - For type-safe variant management
- `@/lib/utils` - For className merging utilities

## API Reference

### Kbd Props

The Kbd component extends `React.ComponentProps<"kbd">` and accepts the following props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "outline" \| "ghost"` | `"default"` | The visual style variant |
| `size` | `"sm" \| "default"` | `"default"` | The size of the key |
| `asChild` | `boolean` | `false` | Render as child element using Slot |
| `className` | `string` | `undefined` | Additional CSS classes to apply |
| `children` | `React.ReactNode` | `undefined` | The key label or symbol |
| ...rest | `kbd` attributes | - | All standard kbd attributes are supported |

### KbdGroup Props

The KbdGroup component extends `React.ComponentProps<"div">` and accepts the following props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | `undefined` | Additional CSS classes to apply |
| `children` | `React.ReactNode` | `undefined` | Kbd components to group together |
| ...rest | `div` attributes | - | All standard div attributes are supported |

### Type Definitions

```typescript
import { VariantProps } from "class-variance-authority";

export interface KbdProps
  extends React.ComponentProps<"kbd">,
    VariantProps<typeof kbdVariants> {
  asChild?: boolean;
}

export interface KbdGroupProps extends React.ComponentProps<"div"> {}
```

## Accessibility

### Semantic HTML

The Kbd component renders as a semantic `<kbd>` element, which is the correct HTML element for representing keyboard input:

```tsx
{/* Properly semantic */}
<p>Press <Kbd>Enter</Kbd> to submit.</p>

{/* Screen reader friendly */}
<KbdGroup aria-label="Keyboard shortcut: Command plus K">
  <Kbd>⌘</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```

### Screen Reader Support

When using symbols, consider adding aria-labels for screen reader users:

```tsx
{/* Good - symbols with labels */}
<Kbd aria-label="Command">⌘</Kbd>
<Kbd aria-label="Shift">⇧</Kbd>

{/* Better - describe the full shortcut */}
<KbdGroup aria-label="Command plus Shift plus P">
  <Kbd>⌘</Kbd>
  <Kbd>⇧</Kbd>
  <Kbd>P</Kbd>
</KbdGroup>
```

## Best Practices

### When to Use Kbd

**Good Use Cases:**
- Displaying keyboard shortcuts in documentation
- Menu item keyboard hints
- Command palette shortcuts
- Tooltip shortcut indicators
- Interactive tutorials and guides

**Avoid Using Kbd For:**
- Regular text content
- Buttons or interactive elements
- Non-keyboard input (use appropriate elements)
- Long text strings

### Design Guidelines

1. **Keep labels short**: Single characters or short abbreviations work best
2. **Use consistent symbols**: Pick either words (Cmd, Ctrl) or symbols and stick with them
3. **Group related keys**: Use KbdGroup for multi-key combinations
4. **Match context**: Use ghost variant for inline text, default for standalone display
5. **Consider size**: Use small size in menus and tooltips

## Implementation Details

### Component Structure

```typescript
function Kbd({ className, variant, size, asChild = false, ...props }) {
  const Comp = asChild ? Slot : "kbd";
  return (
    <Comp
      data-slot="kbd"
      className={cn(kbdVariants({ variant, size }), className)}
      {...props}
    />
  );
}
```

### Variant Implementation

Variants are implemented using `class-variance-authority` for type-safe, composable styles:

```typescript
const kbdVariants = cva(
  "pointer-events-none inline-flex items-center justify-center gap-1 font-mono text-xs select-none [&_svg:not([class*='size-'])]:size-3",
  {
    variants: {
      variant: {
        default: "border border-border bg-muted text-muted-foreground",
        outline: "border border-border bg-transparent text-foreground",
        ghost: "bg-transparent text-muted-foreground",
      },
      size: {
        sm: "h-4 min-w-4 px-1 text-[10px]",
        default: "h-5 min-w-5 px-1.5",
      },
    },
    defaultVariants: {
      variant: "default",
      size: "default",
    },
  }
);
```

## Troubleshooting

### Font not displaying correctly

Ensure JetBrains Mono or another monospace font is loaded:

```css
@import url('https://fonts.googleapis.com/css2?family=JetBrains+Mono&display=swap');
```

### Keys not aligning properly

Use KbdGroup to ensure consistent spacing:

```tsx
{/* Use KbdGroup for proper alignment */}
<KbdGroup>
  <Kbd>Ctrl</Kbd>
  <Kbd>C</Kbd>
</KbdGroup>
```

### Symbols not rendering

Ensure your HTML charset is set to UTF-8:

```html
<meta charset="UTF-8" />
```

### Theme colors not applying

Verify your CSS variables are properly defined in your global styles.
