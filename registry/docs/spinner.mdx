# Spinner

Indicate loading states with terminal-inspired ASCII spinners featuring retro character animations.

## Overview

The Spinner component is a loading indicator designed to communicate ongoing processes to users. Built with a distinctive terminal aesthetic, it features authentic ASCII character animations that evoke the feel of classic command-line interfaces, retro computing, and BBS systems. Each spinner variant uses carefully selected Unicode and ASCII characters that animate through frames to create engaging, nostalgic loading indicators.

## Features

- **8 Animation Variants**: Line, Dots, Cross, Square, Pie, Half, Bar-Vertical, and Bar-Horizontal
- **Terminal-Inspired Design**: Authentic ASCII and Unicode characters from classic CLI spinners
- **Adjustable Speed**: Three speed presets (slow, medium, fast) for different contexts
- **Reversible Animation**: Option to reverse the animation direction
- **4 Size Options**: Small, medium, large, and extra-large for flexible layouts
- **Monospace Typography**: Consistent character width for stable animations
- **Fully Accessible**: Proper ARIA attributes and semantic role for screen readers
- **TypeScript Support**: Fully typed with comprehensive prop definitions

## API Reference

### Spinner Props

The Spinner component extends `React.HTMLAttributes<HTMLSpanElement>` (excluding `children`) and accepts the following props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"line" \| "dots" \| "cross" \| "square" \| "pie" \| "half" \| "bar-vertical" \| "bar-horizontal"` | `"line"` | The animation style variant |
| `size` | `"sm" \| "md" \| "lg" \| "xl"` | `"md"` | The size of the spinner |
| `speed` | `"slow" \| "medium" \| "fast"` | `"medium"` | The animation speed |
| `reverse` | `boolean` | `false` | Reverse the animation direction |
| `className` | `string` | `undefined` | Additional CSS classes to apply |
| ...rest | `HTMLSpanElement` attributes | - | All standard span attributes (except children) |

### Type Definitions

```typescript
import { VariantProps } from "class-variance-authority";

const SPINNER_CHARS = {
  line: ["\\", "|", "/", "-"],
  dots: ["⣷", "⣯", "⣟", "⡿", "⢿", "⣻", "⣽", "⣾"],
  cross: ["+", "x"],
  square: ["◰", "◳", "◲", "◱"],
  pie: ["◴", "◷", "◶", "◵"],
  half: ["◐", "◓", "◑", "◒"],
  "bar-vertical": ["▁", "▃", "▄", "▅", "▆", "▇", "█", "▇", "▆", "▅", "▄", "▃"],
  "bar-horizontal": ["▉", "▊", "▋", "▌", "▍", "▎", "▏", "▎", "▍", "▌", "▋", "▊", "▉"],
} as const;

const SPEED_DURATION = {
  slow: 400,
  medium: 200,
  fast: 100,
} as const;

export interface SpinnerProps
  extends Omit<React.ComponentProps<"span">, "children">,
    VariantProps<typeof spinnerVariants> {
  variant?: keyof typeof SPINNER_CHARS;
  speed?: keyof typeof SPEED_DURATION;
  reverse?: boolean;
}
```

## Best Practices

### When to Use Spinners

✅ **Good Use Cases:**
- Indicating form submission in progress
- Showing content loading states
- Processing API requests
- Long-running operations
- Inline loading indicators in buttons or lists
- Terminal-style command outputs

❌ **Avoid Using Spinners For:**
- Very short operations (< 300ms) - consider skeleton loading instead
- Determinate progress - use progress bars instead
- Background operations that don't block the UI
- Decorative purposes without loading context
- Multiple simultaneous spinners in the same view

### Design Guidelines

1. **Choose appropriate variants**: Use `line` for classic terminal feel, `dots` for modern applications
2. **Match speed to context**: Faster speeds for quick operations, slower for long processes
3. **Size appropriately**: Use smaller sizes for inline indicators, larger for full-page loading
4. **Provide context**: Always include text explaining what's loading when possible
5. **Consider color**: Use semantic colors to indicate the type of operation
6. **Avoid overuse**: Limit to one visible spinner per logical section

### Animation Considerations

- The `line` variant uses 4 frames for a classic terminal look
- The `dots` variant uses 8 frames for smoother animation
- Bar variants use 12-13 frames for fluid bouncing effects
- Speed presets are designed to be visually comfortable

## Design Details

### Character Sets

Each variant uses carefully selected Unicode characters:

| Variant | Characters | Frame Count | Origin |
|---------|-----------|-------------|--------|
| `line` | `\ \| / -` | 4 | Classic ASCII spinner |
| `dots` | Braille patterns | 8 | Modern terminal spinners |
| `cross` | `+ x` | 2 | Minimal alternating |
| `square` | `◰ ◳ ◲ ◱` | 4 | Unicode box drawing |
| `pie` | `◴ ◷ ◶ ◵` | 4 | Unicode pie charts |
| `half` | `◐ ◓ ◑ ◒` | 4 | Unicode circles |
| `bar-vertical` | Block elements | 12 | Progress bar style |
| `bar-horizontal` | Block elements | 13 | Progress bar style |

### Animation Timing

Speed presets are calibrated for optimal visual feedback:

- **Slow (400ms)**: Calm, deliberate - suitable for long operations
- **Medium (200ms)**: Balanced - default for most use cases
- **Fast (100ms)**: Energetic, urgent - for quick operations

### Implementation Details

The spinner uses React's `useState` and `useEffect` for animation:

```typescript
const [frame, setFrame] = React.useState(0);
const chars = SPINNER_CHARS[variant];
const duration = SPEED_DURATION[speed];

React.useEffect(() => {
  const interval = setInterval(() => {
    setFrame((prev) => {
      if (reverse) {
        return prev <= 0 ? chars.length - 1 : prev - 1;
      }
      return (prev + 1) % chars.length;
    });
  }, duration);

  return () => clearInterval(interval);
}, [chars.length, duration, reverse]);
```

## Performance

The Spinner component is lightweight and performant:
- Minimal JavaScript footprint (~1KB)
- Uses `setInterval` for efficient frame updates
- Proper cleanup via `useEffect` return function
- No external animation libraries required
- Server-side rendering compatible (renders first frame)
- Single re-render per frame update

### Optimization Tips

```tsx
// Memoize if spinner props are stable
const MemoizedSpinner = React.memo(Spinner);

// Conditionally render to avoid unnecessary intervals
{isLoading && <Spinner />}

// Use appropriate speed for context
<Spinner speed="slow" /> // For long operations, reduces CPU usage
```

## Troubleshooting

### Spinner not animating

Ensure the component is properly mounted and not conditionally hidden:

```tsx
{/* Make sure isLoading is a boolean, not undefined */}
{isLoading === true && <Spinner />}
```

### Characters not displaying correctly

Some fonts may not support all Unicode characters. The component uses monospace font by default (`font-mono`), which should support most characters. If issues persist:

```tsx
{/* Use a variant with basic ASCII characters */}
<Spinner variant="line" />
<Spinner variant="cross" />
```

### Animation feels choppy

Try adjusting the speed or using variants with more frames:

```tsx
{/* Smoother animation with more frames */}
<Spinner variant="dots" speed="medium" />
<Spinner variant="bar-vertical" speed="slow" />
```

### Memory leaks on unmount

The component properly cleans up intervals on unmount. If you're seeing issues, ensure proper conditional rendering:

```tsx
{/* Correct: Component unmounts when not loading */}
{isLoading && <Spinner />}

{/* Avoid: Always mounted but visually hidden */}
<Spinner className={isLoading ? "visible" : "invisible"} />
```
