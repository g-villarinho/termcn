# Badge

Display status, labels, and metadata with terminal-inspired badge components.

## Overview

The Badge component is a versatile UI element designed to display short pieces of information such as status indicators, labels, tags, or metadata. Built with a terminal aesthetic in mind, it offers multiple visual variants and unique geometric cap styles that set it apart from traditional badge components.

## Features

- **7 Semantic Variants**: Minimal, Subtle, Muted, Elevated, Solid, Bold, and Emphasis
- **6 Geometric Cap Styles**: Square, Round, Triangle, Ribbon, Slant-Top, and Slant-Bottom
- **Terminal-Inspired Design**: Monospace font and theme-aware colors
- **Fully Accessible**: Proper semantic HTML and keyboard navigation support
- **Customizable**: Extend with custom className props
- **TypeScript Support**: Fully typed with discriminated union types

## Installation

```bash
npx termcn add badge
```

This will install the Badge component and its dependencies into your project.

## API Reference

### Badge Props

The Badge component extends `React.HTMLAttributes<HTMLDivElement>` and accepts the following props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"minimal" \| "subtle" \| "muted" \| "elevated" \| "solid" \| "bold" \| "emphasis"` | `"bold"` | The color variant of the badge |
| `cap` | `"square" \| "round" \| "triangle" \| "ribbon" \| "slant-top" \| "slant-bottom"` | `"square"` | The geometric end-cap style |
| `className` | `string` | `undefined` | Additional CSS classes to apply |
| `children` | `React.ReactNode` | `undefined` | The content to display inside the badge |
| ...rest | `HTMLDivElement` attributes | - | All standard div attributes are supported |

### Type Definitions

```typescript
import { VariantProps } from "class-variance-authority";

export interface BadgeProps
  extends React.HTMLAttributes<HTMLDivElement>,
    VariantProps<typeof badgeVariants> {}
```

### Theme Integration

The Badge component uses CSS variables from the TermCN theme system:

- `--background` - Minimal variant background
- `--foreground` - Minimal variant text
- `--muted` - Subtle variant background
- `--muted-foreground` - Subtle variant text
- `--accent` - Muted variant background
- `--accent-foreground` - Muted variant text
- `--card` - Elevated variant background
- `--card-foreground` - Elevated variant text
- `--primary` - Bold variant background
- `--primary-foreground` - Bold variant text
- `--secondary` - Emphasis variant background
- `--secondary-foreground` - Emphasis variant text

### Extending Variants

To add custom variants, modify the `badgeVariants` CVA definition:

```typescript
const badgeVariants = cva(
  "inline-flex items-center border px-2.5 py-0.5 text-xs font-semibold font-mono focus:outline-none focus:ring-2 focus:ring-ring focus:ring-offset-2",
  {
    variants: {
      variant: {
        // ... existing variants
        custom: "border-purple-500 bg-purple-500 text-white",
      },
      cap: {
        // ... existing caps
      },
    },
  }
);
```

## Accessibility

### Semantic HTML

The Badge component renders as a `<div>` element. For better semantics, consider:

```tsx
{/* For status indicators */}
<Badge role="status" aria-label="Active status">Active</Badge>

{/* For count badges */}
<Badge role="status" aria-label="5 unread notifications">5</Badge>

{/* For labels */}
<Badge aria-label="React technology tag">React</Badge>
```

### Screen Reader Support

Ensure badge content is meaningful to screen readers:

```tsx
{/* Good */}
<Badge variant="emphasis">New Feature</Badge>

{/* Better - if badge is purely decorative */}
<Badge aria-hidden="true">★</Badge>
```

## Implementation Details

### Component Structure

```typescript
function Badge({ className, variant, cap, ...props }: BadgeProps) {
  return (
    <div className={cn(badgeVariants({ variant, cap }), className)} {...props} />
  );
}
```

### Variant Implementation

Variants are implemented using `class-variance-authority` for type-safe, composable styles:

```typescript
const badgeVariants = cva(
  // Base styles
  "inline-flex items-center border px-2.5 py-0.5 text-xs font-semibold font-mono focus:outline-none focus:ring-2 focus:ring-ring focus:ring-offset-2",
  {
    variants: {
      variant: { /* ... */ },
      cap: { /* ... */ },
    },
    defaultVariants: {
      variant: "bold",
      cap: "square",
    },
  }
);
```

### Cap Styles Implementation

Geometric caps use CSS `clip-path` for precise shape control:

- `triangle`: Creates arrow-pointed ends using polygon clipping
- `ribbon`: Creates arrow-right shape with left indent
- `slant-top`: Diagonal cuts on top corners
- `slant-bottom`: Diagonal cuts on bottom corners

## Best Practices

### When to Use Badges

✅ **Good Use Cases:**
- Status indicators (active, pending, error)
- Category labels and tags
- Count indicators (unread messages, notifications)
- Version numbers or release stages
- Feature highlights ("New", "Beta", "Pro")

❌ **Avoid Using Badges For:**
- Long text content (use labels or paragraphs instead)
- Interactive elements (use buttons instead)
- Primary navigation (use proper navigation components)
- Critical information that requires immediate action (use alerts)

### Design Guidelines

1. **Keep text short**: 1-3 words maximum
2. **Use consistent variants**: Establish meaning for each variant (e.g., "emphasis" always means "important")
3. **Don't overuse**: Too many badges create visual noise
4. **Consider context**: Choose cap styles that match your design language
5. **Maintain contrast**: Ensure text is readable against background

### Performance

The Badge component is lightweight and performant:
- No JavaScript required for rendering
- CSS-only styling with no runtime overhead
- Minimal bundle size impact (~1KB)
- Server-side rendering compatible

## Troubleshooting

### Badge not displaying correctly

Ensure Tailwind CSS is properly configured to include the badge component styles.

### Clip-path not working

Some older browsers don't support `clip-path`. Consider providing fallbacks:

```tsx
<Badge cap="square" className="supports-[clip-path]:cap-triangle">
  Text
</Badge>
```

### Theme colors not applying

Verify your CSS variables are properly defined in your global styles.
