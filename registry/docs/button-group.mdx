# ButtonGroup

Group related buttons and interactive elements with terminal-inspired layouts and seamless visual cohesion.

## Overview

The ButtonGroup component is a layout utility designed to visually and semantically group related buttons and interactive elements. Built with a terminal aesthetic in mind, it provides a cohesive container that aligns multiple actions together, creating a unified toolbar-like interface. The component supports horizontal and vertical orientations, text labels, and visual separators for organizing complex action sets.

## Features

- **2 Orientation Modes**: Horizontal (default) and vertical layouts for different design needs
- **Terminal-Inspired Design**: Monospace font integration and theme-aware styling
- **Flexible Composition**: Combine buttons, text labels, and separators in any order
- **Text Label Support**: Add contextual labels within button groups using ButtonGroupText
- **Visual Separators**: Distinct ButtonGroupSeparator component for logical grouping
- **Slot Pattern Support**: ButtonGroupText supports asChild for custom element rendering
- **Fully Accessible**: Proper role="group" semantics and keyboard navigation support
- **TypeScript Support**: Fully typed with CVA variant definitions

## Installation

```bash
npx termcn add button-group
```

This will install the ButtonGroup component and its dependencies into your project.

## API Reference

### ButtonGroup Props

The ButtonGroup component extends `React.HTMLAttributes<HTMLDivElement>` and accepts the following props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | The layout direction of the button group |
| `className` | `string` | `undefined` | Additional CSS classes to apply |
| `children` | `React.ReactNode` | `undefined` | The buttons and elements to group |
| ...rest | `HTMLDivElement` attributes | - | All standard div attributes are supported |

### ButtonGroupText Props

The ButtonGroupText component extends `React.HTMLAttributes<HTMLDivElement>` and accepts the following props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `asChild` | `boolean` | `false` | Render as child element using Radix Slot |
| `className` | `string` | `undefined` | Additional CSS classes to apply |
| `children` | `React.ReactNode` | `undefined` | The text content to display |
| ...rest | `HTMLDivElement` attributes | - | All standard div attributes are supported |

### ButtonGroupSeparator Props

The ButtonGroupSeparator component extends `React.HTMLAttributes<HTMLDivElement>` and accepts the following props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data-orientation` | `"horizontal" \| "vertical"` | `"vertical"` | The visual orientation of the separator |
| `className` | `string` | `undefined` | Additional CSS classes to apply |
| ...rest | `HTMLDivElement` attributes | - | All standard div attributes are supported |

### Type Definitions


- **Tab**: Move focus between buttons in the group

## Best Practices

### When to Use ButtonGroup

✅ **Good Use Cases:**
- Toolbar actions (text formatting, media controls)
- Pagination controls with page indicators
- Toggle/segmented controls for switching views
- Related action sets (save/cancel, undo/redo)
- Zoom or quantity controls with value display

❌ **Avoid Using ButtonGroup For:**
- Unrelated buttons that happen to be near each other
- Navigation menus (use proper nav components)
- Form submission areas (use proper form layout)
- Single buttons (no need for grouping)

### Design Guidelines

1. **Group related actions**: Only group buttons that perform related operations
2. **Use separators sparingly**: Add separators to denote logical subgroups
3. **Maintain visual consistency**: Use the same button variant within a group
4. **Consider orientation**: Use vertical for menus, horizontal for toolbars
5. **Limit group size**: Keep groups to 5-7 items maximum for usability
6. **Add context with text**: Use ButtonGroupText to provide clarity

## Implementation Details

### Component Structure

```typescript
function ButtonGroup({
  className,
  orientation,
  ...props
}: ButtonGroupProps) {
  return (
    <div
      role="group"
      data-slot="button-group"
      data-orientation={orientation}
      className={cn(buttonGroupVariants({ orientation }), className)}
      {...props}
    />
  );
}
```

### Variant Implementation

```typescript
const buttonGroupVariants = cva(
  "inline-flex w-fit items-stretch font-mono",
  {
    variants: {
      orientation: {
        horizontal: "flex-row",
        vertical: "flex-col",
      },
    },
    defaultVariants: {
      orientation: "horizontal",
    },
  }
);
```

### Separator Orientation

The ButtonGroupSeparator adapts its dimensions based on orientation:

- **Horizontal group** (default): Separator is vertical (1px width, full height)
- **Vertical group**: Separator is horizontal (full width, 1px height)

## Troubleshooting

### Buttons not aligning properly

Ensure all buttons have consistent sizing:

```tsx
{/* Use consistent size prop */}
<ButtonGroup>
  <Button size="sm">Button 1</Button>
  <Button size="sm">Button 2</Button>
</ButtonGroup>
```

### Separator not visible

Check that the separator has the correct orientation:

```tsx
{/* For horizontal groups, separator should be vertical (default) */}
<ButtonGroup orientation="horizontal">
  <Button>A</Button>
  <ButtonGroupSeparator /> {/* Renders as vertical line */}
  <Button>B</Button>
</ButtonGroup>

{/* For vertical groups, set separator orientation explicitly */}
<ButtonGroup orientation="vertical">
  <Button>A</Button>
  <ButtonGroupSeparator data-orientation="horizontal" />
  <Button>B</Button>
</ButtonGroup>
```

### Gap between buttons

The default styling uses `items-stretch` without gaps. Add custom gap if needed:

```tsx
<ButtonGroup className="gap-1">
  <Button>Spaced</Button>
  <Button>Buttons</Button>
</ButtonGroup>
```

### Theme colors not applying

Verify your CSS variables are properly defined in your global styles:

```css
:root {
  --border: 220 13% 91%;
  --background1: 0 0% 100%;
  --muted-foreground: 220 9% 46%;
}
```
