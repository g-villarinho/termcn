# Separator

Visually divide content sections with terminal-inspired separator lines featuring precise pixel-perfect alignment.

## Overview

The Separator component is a semantic divider element designed to visually separate content sections within your interface. Built on Radix UI primitives with terminal aesthetics in mind, it features precise line-height-based positioning that ensures pixel-perfect alignment in both horizontal and vertical orientations. The component uses advanced CSS linear gradients to create crisp 2px separator lines that integrate seamlessly with the monospace grid system.

## Features

- **Dual Orientation Support**: Horizontal and vertical separators for flexible layout division
- **Line-Height Alignment**: Precise vertical centering using `lh` (line-height) and `ch` (character width) units
- **Pixel-Perfect Rendering**: 2px separator lines using CSS linear gradients for crisp display
- **Terminal Grid Integration**: Dimensions based on typographic units for monospace alignment
- **Radix UI Foundation**: Built on accessible Radix UI Separator primitives
- **Decorative Control**: Toggle between decorative and semantic separator modes
- **Theme-Aware Colors**: Uses `--color-border` CSS variable for consistent theming
- **TypeScript Support**: Fully typed with Radix UI component props

## API Reference

### Separator Props

The Separator component extends `React.ComponentProps<typeof SeparatorPrimitive.Root>` and accepts the following props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | The orientation of the separator |
| `decorative` | `boolean` | `true` | Whether the separator is decorative (hidden from accessibility tree) |
| `className` | `string` | `undefined` | Additional CSS classes to apply |
| ...rest | `SeparatorPrimitive.Root` attributes | - | All Radix UI Separator props are supported |

### Type Definitions

```typescript
import * as SeparatorPrimitive from "@radix-ui/react-separator";

interface SeparatorProps
  extends React.ComponentProps<typeof SeparatorPrimitive.Root> {}
```


## Accessibility

### Semantic Behavior

The Separator uses `role="separator"` by default when `decorative={false}`:

```tsx
{/* Decorative - aria-hidden="true" */}
<Separator decorative={true} />

{/* Semantic - role="separator" */}
<Separator decorative={false} />
```

### Screen Reader Support

- When `decorative={true}` (default), the separator is hidden from the accessibility tree
- When `decorative={false}`, screen readers announce it as a separator
- Use semantic separators for meaningful content divisions

### ARIA Attributes

```tsx
{/* Horizontal separator with aria orientation */}
<Separator decorative={false} aria-orientation="horizontal" />

{/* Vertical separator */}
<Separator
  orientation="vertical"
  decorative={false}
  aria-orientation="vertical"
/>
```

### When to Use Semantic Separators

✅ **Use `decorative={false}` when:**
- Separating distinct sections of content
- Dividing form fieldsets
- Creating meaningful content boundaries

❌ **Keep `decorative={true}` (default) when:**
- Purely visual enhancement
- Spacing elements in toolbars
- Decorative list dividers

## Best Practices

### When to Use Separators

✅ **Good Use Cases:**
- Dividing content sections within cards
- Separating menu item groups
- Creating visual breaks in forms
- Toolbar section divisions
- List item grouping

❌ **Avoid Using Separators For:**
- Primary page structure (use semantic HTML sections)
- Between every item in a list (excessive visual noise)
- When whitespace alone provides adequate separation
- As borders around containers

### Design Guidelines

1. **Use sparingly**: Don't overuse separators - whitespace is often sufficient
2. **Group related content**: Place separators between distinct content groups
3. **Maintain consistency**: Use the same separator style throughout your app
4. **Consider orientation**: Use vertical separators for inline content, horizontal for stacked
5. **Respect spacing**: Add appropriate margin around separators

## Design Details

### Line-Height Based Positioning

The Separator achieves pixel-perfect centering using CSS line-height units:

**Horizontal Separator:**
- Height: `1lh` (one line-height)
- Width: `100%`
- Line positioned at vertical center using gradient stops at `0.5lh ± 1px`

**Vertical Separator:**
- Width: `1ch` (one character width)
- Height: `100%`
- Line positioned at horizontal center using gradient stops at `0.5ch ± 1px`

### CSS Gradient Implementation

```css
/* Horizontal separator */
background: linear-gradient(
  0deg,
  transparent 0,
  transparent calc(0.5lh - 1px),
  var(--color-border) calc(0.5lh - 1px),
  var(--color-border) calc(0.5lh + 1px),
  transparent calc(0.5lh + 1px),
  transparent
);

/* Vertical separator */
background: linear-gradient(
  to right,
  transparent 0,
  transparent calc(0.5ch - 1px),
  var(--color-border) calc(0.5ch - 1px),
  var(--color-border) calc(0.5ch + 1px),
  transparent calc(0.5ch + 1px),
  transparent
);
```

### Why Gradients Instead of Borders?

The gradient approach provides:
- Precise sub-pixel positioning
- Perfect alignment with text baselines
- No layout impact from border-box calculations
- Consistent rendering across browsers

## Troubleshooting

### Separator not visible

Ensure the parent container has sufficient height for vertical separators:

```tsx
{/* Parent needs height for vertical separator */}
<div className="flex h-5 items-center">
  <span>Left</span>
  <Separator orientation="vertical" />
  <span>Right</span>
</div>
```

### Gradient not rendering

Some older browsers may not support the `lh` and `ch` CSS units. Consider fallbacks:

```tsx
<Separator className="h-px bg-border" />
```

### Separator color not matching theme

Verify `--color-border` CSS variable is defined in your theme:

```css
:root {
  --color-border: oklch(0.37 0.01 260);
}
```

### Vertical separator taking full width

Ensure the separator is inside a flex container:

```tsx
<div className="flex items-center gap-4">
  <span>Item 1</span>
  <Separator orientation="vertical" className="h-4" />
  <span>Item 2</span>
</div>
```
