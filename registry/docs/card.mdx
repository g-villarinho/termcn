# Card

Container component with vim-inspired window decorations and terminal-style status line for organizing content.

## Overview

The Card component is a versatile container designed to group and display related content in a structured format. Built with a distinctive terminal aesthetic in mind, it features composable vim-inspired window decorations, mode indicators, buffer names, and a fully-featured status line that emulates the classic vim editor interface.

## Features

- **Composable Architecture**: Build complex UIs by combining simple, focused components
- **3 Visual Variants**: Default, Elevated, and Floating with progressive shadow depths
- **3 Size Options**: Small, Default, and Large text sizing for different content densities
- **Window Decoration Components**: CardWindowBar, CardMode, CardBufferName, CardFileType, CardLinePosition, CardWindowControls
- **Status Line Components**: CardStatusLine and CardStatusSection for building custom status bars
- **Terminal Aesthetics**: Monospace font, sharp borders, and theme-aware ANSI colors
- **Fully Accessible**: Proper semantic HTML and screen reader support
- **TypeScript Support**: Fully typed with comprehensive prop definitions

## Installation

```bash
npx termcn add card
```

This will install the Card component and its dependencies into your project.

## Dependencies

- `class-variance-authority` - For type-safe variant management

## API Reference

### Card Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "elevated" \| "floating"` | `"default"` | The shadow depth variant |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | The text size variant |
| `className` | `string` | `undefined` | Additional CSS classes |
| `children` | `React.ReactNode` | `undefined` | Card content |

### CardWindowBar Props

Container for window decorations. Extends `React.ComponentProps<"div">`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | `undefined` | Additional CSS classes |
| `children` | `React.ReactNode` | `undefined` | Window bar content |

### CardMode Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `mode` | `"NORMAL" \| "INSERT" \| "VISUAL" \| "COMMAND"` | `"NORMAL"` | Vim mode |
| `className` | `string` | `undefined` | Additional CSS classes |
| `children` | `React.ReactNode` | `undefined` | Custom content (overrides mode text) |

### CardBufferName Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `modified` | `boolean` | `false` | Show [+] indicator |
| `readonly` | `boolean` | `false` | Show [RO] indicator |
| `className` | `string` | `undefined` | Additional CSS classes |
| `children` | `React.ReactNode` | `undefined` | Buffer/file name |

### CardFileType Props

Extends `React.ComponentProps<"span">`. Renders file type in cyan.

### CardLinePosition Props

Extends `React.ComponentProps<"span">`. Renders line position in muted color.

### CardWindowControls Props

Extends `React.ComponentProps<"div">`. Renders macOS-style colored dots.

### CardStatusLine Props

Container for status line sections. Extends `React.ComponentProps<"div">`.

### CardStatusSection Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"mode" \| "buffer" \| "spacer" \| "info" \| "position"` | `"info"` | Section variant |
| `modeColor` | `"default" \| "blue" \| "green" \| "magenta" \| "yellow" \| "cyan"` | `"default"` | Background color |
| `className` | `string` | `undefined` | Additional CSS classes |
| `children` | `React.ReactNode` | `undefined` | Section content |

### Core Sub-components

| Component | Description |
|-----------|-------------|
| `CardHeader` | Header section with bottom border and background |
| `CardTitle` | Title text with semibold styling |
| `CardDescription` | Description text in muted color |
| `CardContent` | Main content area with padding |
| `CardFooter` | Footer section with top border and background |
| `CardAction` | Container for header actions (auto-aligns right) |

## Styling and Customization

### Custom Styles

You can extend the card with custom styles using the `className` prop:

```tsx
<Card className="w-full max-w-md">Full Width Card</Card>
<Card className="bg-ansi-blue/10 border-ansi-blue">Colored Card</Card>
<Card className="hover:border-primary transition-colors">Interactive Card</Card>
```

### Theme Integration

The Card component uses CSS variables from the TermCN theme system:

- `--card` / `--card-foreground` - Card background and text
- `--background` / `--background1` / `--background2` / `--background3` - Layer backgrounds
- `--border` - Border color
- `--foreground` / `--foreground2` - Text colors
- `--muted-foreground` - Subdued text
- `--ansi-blue`, `--ansi-green`, `--ansi-magenta`, `--ansi-yellow`, `--ansi-cyan`, `--ansi-red` - Mode colors

### Mode Color Mapping

| Mode | Background Color | Purpose |
|------|-----------------|---------|
| NORMAL | `bg-ansi-blue` | Default editing mode |
| INSERT | `bg-ansi-green` | Active text input |
| VISUAL | `bg-ansi-magenta` | Selection mode |
| COMMAND | `bg-ansi-yellow` | Command entry |

### Status Line Layout

The composable status line follows the classic vim statusline structure:

```
[MODE] [buffer_name] [+/-RO] -------- [filetype] [line,col] [percentage]
```

## Accessibility

### Semantic HTML

The Card component renders as a `<div>` element. For better semantics, consider:

```tsx
{/* For article-like content */}
<Card role="article">
  <CardContent>...</CardContent>
</Card>

{/* For grouped content */}
<Card role="group" aria-labelledby="card-title">
  <CardHeader>
    <CardTitle id="card-title">Title</CardTitle>
  </CardHeader>
</Card>

{/* For widget regions */}
<Card role="region" aria-label="System status">
  <CardContent>...</CardContent>
</Card>
```

### Screen Reader Support

Ensure card content is accessible:

```tsx
{/* Good - meaningful structure */}
<Card>
  <CardHeader>
    <CardTitle>Notifications</CardTitle>
    <CardDescription>You have 3 unread messages</CardDescription>
  </CardHeader>
  <CardContent aria-live="polite">
    {messages.map(msg => <p key={msg.id}>{msg.text}</p>)}
  </CardContent>
</Card>

{/* For decorative status line elements */}
<CardStatusLine aria-hidden="true" />
```

```tsx
    <CardStatusSection variant="position">Top</CardStatusSection>

</Card>
```

### When to Use Cards

**Good Use Cases:**
- Grouping related content (profile info, settings)
- Dashboard widgets and metrics
- Code snippets and terminal output
- Notification or alert containers
- Form sections and wizards
- Preview panels and modals

**Avoid Using Cards For:**
- Single pieces of unrelated content
- Wrapping entire pages (use layout components)
- Navigation menus (use nav components)
- Inline content that doesn't need grouping

## Related Components

- **Badge**: For status indicators within cards
- **Button**: For actions in card headers and footers
- **Dialog**: For modal card-like overlays
- **Alert**: For status messages with similar structure
- **Separator**: For dividing card content sections
